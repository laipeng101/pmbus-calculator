# PMBus Calculator v2.2.0

MINOR release — M37 LINEAR 指数编辑器与 VOUT_MODE 结构化配置器。

> 2026-08-26 · MINOR（向后兼容）· PMBus Rev 1.3 / SMBus 3.0

本版本在 M36 result-first 布局之上，为 L11/L16 LINEAR 提供共享公式编辑器（N 真正位于底数 2
的指数槽），为 L16 提供 VOUT_MODE 结构化配置器，并纠正三处 VOUT_MODE 分类/校验缺陷与一处
Hex 输入过渡态缺陷。算法、舍入、饱和、字节序、raw word 与命令参考只读语义均未改变。

## 已修复缺陷

| 缺陷                                                             | 规范依据                                | 用户可见变化                                                          |
| ---------------------------------------------------------------- | --------------------------------------- | --------------------------------------------------------------------- |
| relative 非 LINEAR 被误标“相对 LINEAR”（0xA0 实为 relative VID） | Part II §8.3 Table 2 / §8.5.3           | 0xA0 现显示“相对 VID — 非法组合（§8.5.3）”，不给出电压结果            |
| DIRECT / IEEE Half 参数非零未判非法（0x5F、0xE1）                | Part II §8.3 Table 2（参数必须 00000b） | 现显示“invalid parameter”，可解码但不可作为有效配置                   |
| L16 同时保存 voutMode 与派生 n，可构造矛盾状态                   | §8.3（N 来自 bits[4:0]）                | 删除 l16.n，VOUT_MODE byte 为 exponent 唯一事实来源                   |
| Hex 空串/裸 0x 聚焦中即提交或报错                                | docs/UI_CONVENTIONS.md 输入合同         | 编辑中暂存为 draft；空串 blur 归一化为 0，裸 0x blur 后报“输入不完整” |

## 新增交互

- 共享 LINEAR 公式编辑器：L11（Y × 2^N）与 L16 LINEAR（V × 2^N）复用同一视觉；
  N 控件锚定到底数 2 的右上指数槽，锁按钮在独立槽，-16/-1/15 与锁定切换时锚点不漂移。
- L16 VOUT_MODE 结构化配置器：Absolute/Relative（bit7）、格式（bits[6:5]）、
  参数（bits[4:0]，按格式呈现 signed N / unsigned VID code / 固定 0）双向同步，
  实时显示 canonical byte + 8-bit binary + 明确合法性状态；expert Hex 与结构化控件互为反向更新。
- VID 语义：Relative 对 VID 不可用（选择 VID 时规范化回 Absolute）；00h Not Used、
  1Eh/1Fh 制造商自定义、其余保留 code 均明确分类，不虚构 CPU 电压映射。
