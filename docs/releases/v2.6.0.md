# PMBus Calculator v2.6.0

MINOR release：全局帮助浮层体系（M42）——概念术语气泡推广到全应用代表放置面、
全部按钮/按钮型控件获得统一的悬停与键盘焦点说明、两类浮层全局单开、原生
`title` 帮助移除并有门禁防回潮、死代码清理。

**本版本不改变任何 PMBus 数据格式的数学语义**：LINEAR11/LINEAR16/DIRECT/HALF
的表示关系、舍入策略、signed-zero 与特殊值合同、provenance 与资源边界全部
不变。所有变更都在帮助/解释呈现层与测试基础设施。

## 变更范围

1. **术语气泡（disclosure 语义）全局放置**：页头（PMBus / binary16 / SMBus）、
   五种模式工作区、结果区（原始 Hex / LE / BE / 量化误差）与命令参考（事务）
   的代表术语全部可点击展开解释；每个概念至少一个生产放置面由
   `TERM_PLACEMENT_SURFACES`（`src/app/terminology.ts`）契约守护。术语数据
   新增 `source`/`specRef`/`scope` 元数据；**LINEAR11 指数 N（word bits[15:11]）
   与 VOUT_MODE 参数 N（bits[4:0]）拆分为两个独立概念**，消除「同一个 N」
   的语义混用。
2. **控件说明（tooltip 语义，`ControlTooltip`）**：模式 tab、主题切换、LINEAR11
   N 锁、VOUT_MODE 绝对/相对值与格式 radio、规范化/应用示例/说明折叠、位编辑
   按钮、复制/前缀/空格/字节序按钮、计算过程/命令参考/调试折叠全部接线；
   文案单一来源是 `src/app/control-help.ts` 的 typed `CONTROL_HELP` registry。
   触发合同：fine-pointer 悬停即显即关（matchMedia + pointerType 双门禁，触屏
   首 tap 不被劫持）、`:focus-visible` 打开、blur/Escape 关闭、click 原动作
   只执行一次、`role="tooltip"` + `aria-describedby`、无 `aria-expanded`。
3. **全局单开**：两类浮层共享 `HelpOverlayProvider` 的 active surface（实例级
   key），打开任一浮层自动关闭另一个；外点关闭与 Escape（含焦点恢复）由单一
   document 监听负责；悬停是高频瞬态 UI 状态，不进入主 reducer、不持久化。
4. **原生 `title` 帮助移除**：主题切换、LINEAR11 N 锁、VID 相对值三处删除；
   `check:no-title-help` 门禁（verify 链 + CI quality job）拒绝 `src/` 下
   一切原生 title 属性。VID 下「相对值」不可用的原因改为浮层之外的可见段落
   （原生 disabled 不产生指针/焦点事件，禁用原因必须有可见路径）。
5. **维护性**：`vout-mode-formats.ts` 消除格式标签/术语双副本；删除零引用的
   `src/components/result/ResultInspector.tsx`（`result-panel` live-region
   合同由 ResultSummary 持有）；UI_CONVENTIONS §7 重写为「帮助浮层：术语气泡
   与控件说明」双合同。

## 诚实陈述

1. **数学语义零变更**：未触碰 `decodeLinear11`/`encodeLinear11`/
   `findBestLinear11`/`decodeLinear16`/`encodeLinear16`/`decodeDirect`/
   `encodeDirect`/`decodeHalf`/`encodeHalf`/`parseVoutMode`/`calculatePEC`
   及其 golden case；数值呈现真值不变。
2. **视觉基线更新共两波、均有逐图审查记录**：Phase 3（术语推广）28 张全部
   更新——差异是页头与各模式新增的下划线术语触发器与预期文案；Phase 4
   （视觉场景静止态归一）8 张 stress 基线更新——v2.6.0 起真实鼠标点击/键盘
   Tab 会在控件上打开说明，visual 场景改为截图前指针归零（`parkPointer`）、
   输入提交后释放焦点（fillRaw blur），差异仅为不再入镜的 bit 15 焦点环与
   焦点浮层，数值与布局逐图核对不变；其余 20 张基线在该波零变化。全部
   28 张最终在静止态下与基线一致。
3. **一个 Chromium 输入时序怪癖按测试时序处理**：点击原地替换图标节点的控件
   （如 N 锁）后立刻移开指针，Chromium 可能在新位置命中测试前于旧坐标补发一次
   phantom pointerenter 导致浮层重开（下一次交互自愈）。产品合同不变；相关
   E2E 在点击后让一帧再移开，并留注释说明。
4. **`VoutModeComposer` 的相对值按钮不再声明 `aria-disabled`**：原生
   `disabled` 已足够，禁用原因由可见段落 + tooltip 承载；radio 组的键盘
   导航行为不变。
5. **删除口径**：仅删除零引用的 `ResultInspector.tsx`；不删除任何 visual
   基线、发行历史、legacy HTML、规范 manifest、独立 oracle 或 lockfile。
