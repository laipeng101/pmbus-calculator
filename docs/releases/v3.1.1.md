# PMBus Calculator v3.1.1

PATCH release：修复 DIRECT 物理值复制回录静默改变 raw 的 P1 缺陷，并把
DIRECT 的显示安全、复制、警告、量化注记与计算步骤统一到同一文本回录合同
（ADR 0007）。全部受保护算法（`decode/encodeLinear11`、`findBestLinear11`、
`decodeLinear16`、`encodeLinear16`、`decode/encodeDirect`、`decode/encodeHalf`、
`parseVoutMode`、`calculatePEC`、`encodeUlinear16`、`encodeSlinear16`）、
canonical Raw Word 领域模型（v3.0.0）、typed 提交精确编码合同（v2.5.11）、
4096 精确 lexeme 资源门禁、请求 provenance、untouched blur no-op、复制格式
与持久化偏好零变更。

## 为什么是 PATCH（向后兼容缺陷修复）

RELEASING「稳定公共契约」五项全部不变：计算与舍入语义（`encodeDirect` 的
Math.round + signed16 clamp 合同原样）、raw word/字节序/复制格式、命令元数据
行为、已持久化偏好、README 声明的用户流程。本版修复的是 v2.5.11「安全回录
承诺」的执行缺口：承诺说「物理值复制返回可安全回录的文本」，但安全判定用的是
binary64 管线回程，而不是用户实际回输的显示文本经真实 typed 路径的结果。

## 缺陷与修复

**缺陷（独立只读审计 PMBUS-AUDIT-20260905 实证）**：m=1、b=1、R=12、raw
FFFF 的精确物理值是 -1.000000000001，binary64 可承载且管线回程安全——于是
无任何告警；但显示文本 `-1`（canonical 12 位有效数字呈现）经真实 typed 提交
编码为 Y=0：复制 → 粘贴 → 提交后 raw 从 FFFF 静默变为 0000。该系数下全
65536 个 Y 中 29491 个如此；(7,3,12) 族 56172/65536 不安全且 0 告警；
(1,1,17) 族也有 4427 个旧守卫安静但复制不安全的状态。另一个呈现诚实性缺口：
循环有理数（如 m=3、b=1、R=16 的精确值 -1/3）的安全回录文本是经验证近似，
却被标注为「精确文本」；m=0 时复制按钮仍启用并复制 `—` 占位符。

**修复**：

1. **单一事实源**：新增 `direct-exact.analyzeDirectTextReentry(y, m, b, r)`——
   显示文本（与结果卡/输入框/复制同源的 `formatPlainNumber` 输出）经与
   reducer 完全相同的 typed 合同（classify → 精确 parse → 精确 encode）回编，
   判定是否回到当前 Y。警告（`direct-precision-fold`）、量化读数注记、计算
   步骤精确值行、复制 override/disable 全部消费同一解析，不再各自用旧
   Number guard 重建结论。
2. **损失分层如实呈现**：`lossKind` 区分 `binary64-representation`（binary64
   值本身回编即改变 payload，v2.5.11 已覆盖的族）与 `display-formatting`
   （binary64 值可安全回录、仅显示文本不行，本版新覆盖的族）；文案不再把
   所有折叠一律称为「超出 binary64 精度」。
3. **复制 payload 恒经验证**：显示文本可安全回录时安静复制显示文本；不可时
   复制经验证回录文本并以 `exact`（终止小数精确展开）/`approximate`（循环
   有理数的经验证有限近似）如实标注；无法生成验证文本时禁用复制并给出原因。
4. **m=0**：物理值复制禁用并给出可访问原因，不再复制 `—`。

## 用户可见行为变化

- (1,1,12) 等 display-formatting 族：此前无告警、复制显示文本（回录会改变
  raw）；现在提交前出现「不同的请求」警告，复制返回经验证文本（如
  `-1.000000000001`），粘贴提交后 raw 不变。
- (3,1,16) 等循环小数族：复制说明与控件 tooltip 明示「经验证可回录的近似
  文本（精确值是循环小数）」，不再冒充精确值。
- 个别 b64 值不安全但显示文本可安全回录的状态（如 (3,1,17) 的 Y=32767）从
  告警变为安静——复制显示文本已可证回到当前 raw，无用户可见危害。
- m=0：物理值复制按钮禁用并显示原因。

## 验收向量（golden）

- (1,1,12) raw FFFF：显示 `-1`、警告可见（回编 Y=0）、复制
  `-1.000000000001`（exact kind）、真实剪贴板回录后 raw 保持 FFFF。
- (3,1,16) raw 0000：显示 `-0.333333333333`、复制
  `-0.33333333333333333`（approximate kind，说明含「循环小数」）、回录后
  raw 保持 0000。
- 安静对照：(1,1,12) raw 0001 显示 `-0.999999999999` 可安全回录，无任何
  保真表面；(1,0,0) raw 000C 显示 `12` 保持安静。
- 既有保护族：(1,1,17) raw FFFF 复制 `-1.00000000000000001` 回到 FFFF
  （v2.5.11 合同不回归）。
- 性质：(1,1,12) 全 65536-Y「最终复制文本 → classify → 精确 parse → 精确
  encode → raw 不变」零违例；29491 个 Y 走 override 路径。
