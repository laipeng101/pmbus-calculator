# PMBus Calculator v1.1.1

PATCH 修复发行：修复 v1.1.0 已确认的 Markdown、命令下拉框、界面一致性、无障碍和自动发布流程缺陷。

发布渠道：GitHub Release（不发布 npm 包）。

## Fixed

- **Markdown 数学公式**：移除 GitHub 会拒绝的 `\operatorname`；README / README_zh-CN / DOMAIN_MODEL 中 HALF 表格改为“IEEE 754 binary16 分段解码”文字定义；修复 UI_CONVENTIONS 中原始 fenced-block 示例；新增 `npm run check:markdown-math`。
- **命令下拉框**：使用 `@floating-ui/react-dom` 实现 viewport-aware floating positioning，portal 渲染，默认 `bottom-start`，空间不足自动 `flip`，`shift`/`size` 保证 viewport 内完整可见；搜索框始终可见；options list 内部滚动；保留键盘与焦点行为；触发器和 listbox 语义关系正确。
- **公式展示**：DIRECT 纯文本修复 `10^(--1)`、`--3`、`10^(-0)`；HALF 按 sign/exponent/fraction 分类显示 zero / subnormal / normal / ±Infinity / NaN；KaTeX MathML 不再被外层 `role`/`aria-label` 覆盖；fallback 才提供可访问名称。
- **视觉系统**：建立语义 surface/control/border/focus token；暗色 hover 提亮；移除全局 `filter: brightness` hover；桌面两栏断点 960px，结果栏 340px sticky；移动端减少外层圆角与边距；控件高度统一 40px；图标替换 emoji。
- **无障碍**：模式切换实现完整 ARIA tabs 键盘行为（Arrow/Home/End/tabIndex/aria-controls）；复制偏好与位按钮 `aria-pressed`；焦点环亮暗主题可见。
- **复制反馈**：使用受控 timer 维持 1.8s，reduced-motion 下不再瞬间消失；CSS 动画只负责淡入淡出。
- **调试面板**：正式 Pages 默认隐藏，仅 `import.meta.env.DEV` 或 `?debug=1` 显示。
- **发布流程**：补充 `github-pages` environment branch/tag policy，允许 `main` branch 与 `v*.*.*` tag，使 release event 可自动触发 Pages。

## Install / Run

```bash
npm ci
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 生产构建到 dist/
npm run preview  # 预览 dist/
```

## Build Artifact

`pmbus-calculator-v1.1.1-web.zip` 包含 `dist/` 的可部署静态内容。校验：

```bash
sha256sum -c SHA256SUMS.txt
```

## Known Limitations

- 自动化浏览器验证仍以桌面和移动 Chromium 为主。
- 当前规范基线为 PMBus Rev 1.3，不声明 PMBus 1.5 兼容。
- 公式不接受用户输入任意 TeX；仅内部受控模板通过 KaTeX 渲染。
