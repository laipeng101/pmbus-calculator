# PMBus Calculator v2.5.15

PATCH release：验收目标真实性（完整语义 E2E 以生产构建为主要验收目标）、
发布文档命令门禁的两个假阳性修复、焦点测试合同纠正与维护说明对齐。

**本版本没有任何 `src/` 产品源码变更**：LINEAR11/LINEAR16/DIRECT/HALF/
VOUT_MODE 的全部数学语义、呈现真值与用户流程不变。版本徽标从 v2.5.14 变为
v2.5.15 属于维护 PATCH 的预期变化。

## 诚实陈述

1. **不改变任何 PMBus 数据格式的数学语义。** 表示关系、舍入策略、signed-zero
   与特殊值合同、4096 字符资源边界全部不变；未发现新的 P0/P1 数值错误，
   本轮不因「寻找重大产品错误」而改动任何正确行为。
2. **发布文档命令门禁修复的是门禁自身的假阳性，不是已发布资产**：提取器曾在
   第一个空格包围的 `>` 处截断全部后缀（反例 A：`--mode draft >
draft-verified.json --unsupported` 被当干净命令校验通过，真实 CLI 对未知
   flag exit 2）；引号不平衡的 token（反例 B：缺结束引号的
   `--metadata "draft-release.json`）被 fixture 替换热值后假通过，而真实
   shell 无法解析。两者均在隔离 fixture 中对旧 checker 复现（旧结果
   ok=true、executed=2）。修复后语法合同显式为「至多一处尾部 stdout 文件
   重定向 + 逐 token 引号平衡」，不支持形态显式拒绝而非静默截断/修复。
   v2.5.14 及更早的已发布资产不受影响、不追溯改写任何历史结论。
3. **焦点测试纠正的是测试的错误起点假设，不是产品缺陷**：原「hover、active
   与 focus-visible」测试在鼠标交互后 blur 并按 Tab，假设 activeElement
   必然是 BUTTON/INPUT 且有 focus-visible。生产 DOM 中 `#command-reference-toggle`
   是页尾最后一个可聚焦控件，HTML 顺序焦点导航允许在页面末尾转向浏览器
   控件（参考 WHATWG HTML §sequential focus navigation 与 Chrome 团队对
   focus 起点的说明）。preview 构建实测判别：普通 URL 下 Tab 后
   activeElement 为 BODY、focus-visible=false；同一构建加 `?debug` 后
   DOM 末尾多一个调试按钮，Tab 落到该按钮且 focus-visible=true——足以证明
   dev（自动渲染调试抽屉）与 production 的 DOM 差异会影响原断言。本轮
   **没有**定位任何 Chromium 缺陷，也没有改任何生产组件：focus-visible 现在
   从 fresh load 的真实 Tab 进入，断言预期具体控件与 outline，并在页内相邻
   控件间 Tab/Shift+Tab 往返；不要求浏览器在页尾最后控件之后仍留在页面内。
4. **E2E 主要验收目标从 dev 切换为生产构建**：桌面语义套件（310）与
   mobile-contract（14）对 `vite preview` 服务的精确 `dist/` 运行（挂载在
   官方 `/pmbus-calculator/` 前缀下），release smoke 消费同一 dist 不重复
   build，verify 链与 CI e2e job 在浏览器套件前只构建一次。所有 preview
   webServer strictPort + `reuseExistingServer:false`——已有 dist 不等于当前
   SHA 已构建，未知/过期服务器不能冒充绿灯。此前发布后在 /tmp 复制并改写
   305 份 spec 逻辑做正式站验收的流程不再作为常规存在：正式站以关键差异
   矩阵 + deployment smoke + 65 文件同源证明为主。dev server 只保留
   canonical visual 世界（28 张基线、环境与快照全部不变）。
5. **URL 合同**：新增 `tests/e2e/helpers/app-url.ts` 纯函数（部署前缀由
   目标配置经 `E2E_APP_BASE_PATH` 声明，保留前缀与末尾斜线，拒绝 `..` 段与
   相对形态）——此前 112 处 `page.goto('/')` 相对 baseURL 根解析，会丢弃
   `/pmbus-calculator/` 前缀。25 个套件 spec 全部迁移；新增
   `app-base-url.spec.ts` 锁定生产构建守卫（无 `/@vite/` 脚本）、前缀保留、
   资源同源成功且非 HTML fallback、`?debug` 入口保留前缀。
6. **维护说明对齐**：REPOSITORY_HYGIENE 不再手工复制清理器目标列表（副本
   已漂移且误称 cleaner 只删除目录），例外章节不再暗示存在大小 allowlist；
   新增 Playwright 配置↔清理器常量一致性测试双向守护。CONTRIBUTING 不再
   复制不完整的 `verify:light` 步骤列表（曾漏 release-docs 门禁）。
7. **删除口径**：不删除任何 visual 基线、发行历史、legacy HTML、规范
   manifest、独立 oracle 或 lockfile；不做历史重写或体积瘦身。测试覆盖
   只增不删：desktop 305→310、mobile 14、release smoke 1、deployment 4、
   visual 28。
