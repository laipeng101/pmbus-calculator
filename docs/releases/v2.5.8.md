# PMBus Calculator v2.5.8

PATCH release — 修复输入数值真实性、参考值恢复与发布资产就绪三类缺陷：解析层
静默限幅（`1e21` 编码为 `0000`、`1e400` 变 `1e20`）、relative L16 标称参考值
无法清除、发布流程先公开后上传导致 Pages 竞态失败。

> 2026-08-28 · PATCH（向后兼容 bugfix）· PMBus Rev 1.3 / SMBus 3.0

## 诚实声明：行为变化的确切范围

本轮**没有**重写任何编码/解码数学：`encodeDirect` 的 legacy `Math.round`/clamp、
HALF round-to-nearest-even、LINEAR11/16 饱和边界、字节序与复制合同全部不变。
变化的是此前错误的输入处理与发布行为，逐项如下（不是笼统的「显式输入行为
完全不变」）：

1. **大值的解析结果变了**：旧解析层把 `|x| > 1e20` 的有限值悄悄截断到
   `±1e20`。修复后完整有限值按真实 double 提交——DIRECT m=1,b=0,R=-21 的
   `1e21` 从错误 raw `0000` 变为正确 `0001`，量化误差基线从假请求 `1e20`
   变为真实请求 `1e21`。依赖旧截断行为的用法会看到不同（正确的）结果。
2. **`±1e400` 从「静默变 1e20」变为「明确范围错误」**：包括 HALF 在内的所有
   模式都不再提交这类文本；旧 raw 与请求保持不变。HALF 的显式字面量
   `NaN` / `±Infinity` 不受影响。
3. **relative L16 的标称参考值可以清除了**：全选删除后 blur/Enter 提交
   null（此前静默恢复旧值）；null 与显式 0 不同；清除后最终电压为 `—`，
   公式/步骤/复制不再输出旧标称推出的电压。非空过渡态 blur 改为归一化
   提交（与物理值输入一致），不再静默恢复。
4. **发布流程顺序变了**：Release 现在 draft → 上传资产 → 回验 → publish；
   Pages 在读取资产前增加就绪门禁。用户可见产品行为不变。

## Fixed

- **解析器静默限幅（P1）**：`parseFloatSafe` 的 `if (n > 1e20) n = 1e20`
  （及其负向分支）在编码器之前改写用户请求，污染 provenance 与误差基线。
  DIRECT m=1、b=0、R=-21：`1e21` → 错误 `0000`（`y=round(1e20×10⁻²¹)=0`），
  正确编码应为 `y=1` → `0001`；直接输入 raw `0001` 本可正确解码为 `1e21`。
  现在共享解析分类 `classifyFloatText` 是 ValueInput / NominalVoutInput /
  reducer 的单一来源：有限值不限幅（`1e21 → 0x0001`、`-1e21 → 0xFFFF`、
  m=-1 对照 `0xFFFF`、R=±128 可表示向量精确往返）；饱和/溢出由既有编码器
  与量化读数处理，请求基线保留原始提交值；完整但溢出为 ±Infinity 的十进制
  文本（`±1e400`）报明确数值范围错误、不改旧 raw、不生成新请求，且
  `isTransitionalFloatText` 不会把它误判为过渡态；HALF 显式字面量
  `NaN`/`±Infinity` 与十进制溢出是两类输入（Part II §7.6）。
- **relative L16 标称参考值不可清除（P1）**：`AppState.l16.nominalVout`
  类型允许 null，但 UI/reducer 没有清除路径，E2E 还把「清空后恢复旧值」
  固化为合同。现在真实清空 + blur/Enter 派发 `l16/clear-nominal-vout`
  （幂等，只影响标称通道）；`null` 与 `0` 是两个状态；最终电压显示 `—`
  与缺失说明；公式、步骤与复制不再输出旧标称电压；重新输入合法值恢复。
  非空非法文本保留字段错误与最后有效值；非空过渡态 blur 归一化提交。
- **发布资产就绪竞态（P1）**：v2.5.7 的 Release 于 05:19:42Z 公开、ZIP 于
  05:19:58Z 才上传，release-published 触发的 Pages 下载步骤在资产不存在时
  失败；旧日志只有 exit 4（`jq -er` 资产未找到同码），「runner 瞬时故障」
  只是猜测。修复为 draft → 上传 → `release-assets-verify.mjs` 回验
  （state=uploaded、size>0、URL 有效、名称唯一、draft/prerelease/tag 合同，
  退出码 2–8 逐类报错）→ publish；Pages 侧只下载脚本解析的 URL、先核对
  字节数再走 checksum/ZIP 合同，全部在部署动作之前 fail-closed；网络调用
  带 timeout 与仅针对瞬时故障的有限重试；无 sleep 等待、无锁/journal。
