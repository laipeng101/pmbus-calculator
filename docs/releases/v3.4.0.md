# PMBus Calculator v3.4.0

MINOR release：把结果工作区收敛为一个更一致、低重复、可解释的工程仪表——数值模式
右侧只保留 `字段/参数` + **一条完整等式**（符号关系 → 当前值代入 → 最终结果），
VOUT_MODE 继续作为结构化位域配置解析，“计算过程”只保留首屏没有的补充诊断。

本源码的发行目标为 v3.4.0；在对应稳定 GitHub Release 公开前按待发布处理。
本文描述版本内容；实际发行和部署状态以 GitHub Release / Pages 验收记录为准。

## 结果工作区收敛

- `src/app/result-workspace.ts` 是五模式共享的唯一结构：数值模式两行
  `字段/参数`、`数值代入`；VOUT_MODE 三行 `字段`、`位解析`、`结果`。
- `src/app/formula-presentation.ts` 新增 `equationLatex` / `equationPlainText`
  （首屏完整等式）与 `symbolicLatex` / `symbolicPlainText`（纯符号关系），
  终值直接绑定同一 canonical headline 文本；复制与 C 宏路径保持字节不变。
- 结果上下文固定 `raw` / `format` / `parameters` / `context` 四逻辑槽位；
  `parameters` 为结构化 label/value（`ResultContextParamVM`），组件不再按字符串切分。
- `terminology.ts` 仍是唯一 glossary；新增术语只覆盖真实显示且可点击的符号，
  放置覆盖矩阵 E2E 扩展到 L16 signed-offset 与 relative ULINEAR16 分支。

## 计算过程与 HALF 可读性

- “计算过程”只保留首屏没有的饱和、精确有理数/精度舍入、量化误差、标称参考与
  溢出/下溢诊断；普通解码返回空列表并整体省略容器。
- HALF 的 `(-1)^s` 经单一共享 helper 以 `(-1)^{\textstyle s}` 排版，纯文本保持
  `(-1)^s`；结果数学行使用专用滚动容器，页面主体无横向溢出。
