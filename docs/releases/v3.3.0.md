# PMBus Calculator v3.3.0

MINOR release：为官方 GitHub Pages 增加页面级 Cloudflare Web Analytics
和可访问的源码仓库图标链接。普通源码构建、自托管与 Release Web ZIP 的默认
无 Analytics 合同保持不变。

本源码的发行目标为 v3.3.0；在对应稳定 GitHub Release 公开前按待发布处理。
本文描述版本内容；实际发行和部署状态以 GitHub Release / Pages 验收记录为准。

## 官方 Pages 功能与隐私

- 正式 Pages 在页头主题按钮旁提供一枚指向
  `https://github.com/laipeng101/pmbus-calculator` 的源码仓库图标链接。
  链接位于 React `#root` 外，使用原创通用 source-code SVG、`currentColor`
  和中文可访问名称“在 GitHub 查看项目源码”；新窗口带 `noopener noreferrer`。
  40–44px 点击目标、亮暗主题、清晰键盘焦点和移动端 safe area 都有专门合同。
  链接随页头滚动，不压缩计算器宽度，也不覆盖下方控件与结果交互。
- Cloudflare Web Analytics 只用于面向隐私的页面级聚合统计。不增加行为参数，
  不把计算器输入/结果、PMBus raw word、物理值、DIRECT 系数、VOUT_MODE 或
  复制内容作为自定义 analytics event 收集。
- clone、Download source ZIP、fork、普通 `npm run build`、Release Web ZIP 与
  自托管默认无 Analytics、无外部 tracking，也无该图标或 `pages-overlay.css`。
  新功能仅存在于官方 Pages 最终部署 payload。

## Release 基线与部署合同

1. 保留全部稳定 Release metadata、annotated tag、checksum、ZIP safety 验证。
2. 从精确 tag fresh build 并重新生成 ZIP，与下载的 Release ZIP 逐字节比较；
   然后运行本地 Release smoke，证明同源资源与无 Analytics / Pages-only UI。
3. 将已验证的下载 ZIP 解压为 `_site`，执行确定性 Pages-only overlay，再用独立
   verifier 与本地 browser smoke 校验 FINAL `_site`，之后才 upload / deploy。
4. 下载 ZIP 与 rebuilt ZIP 始终保持原字节。最终 `_site` 的 `index.html` 与新增
   `pages-overlay.css` 有意不同于纯 Release 基线；live entity verifier 以这个
   FINAL `_site` 动态生成 byte manifest，然后才执行真实 Pages remote smoke。

overlay 缺失 token、目录/文件不合格、未知 CSP、重复 beacon/marker、错误仓库
链接或多余第三方资源时 fail closed；第二次 overlay 明确失败。相同 Release tree
和相同部署输入产生相同输出。所有可准备门禁均在 deploy-pages 前，失败不动线上旧站。

Release CSP 的来源仍是 `vite.config.ts`，不增加外部域。只有 Pages overlay 允许：

- `script-src 'self' https://static.cloudflareinsights.com/beacon.min.js`
- `connect-src 'self' https://cloudflareinsights.com`

其他 directive 保持语义不变；应用 JS/CSS、KaTeX 字体和 overlay CSS 继续同源。
Cloudflare beacon 不下载/vendor、不添加未受支持的 SRI，不允许 wildcard 或
宽泛 `https:`。Remote smoke 只额外允许精确 beacon script GET 与
`POST https://cloudflareinsights.com/cdn-cgi/rum`（fetch/xhr/ping/other），
拒绝额外 query、path、protocol、port、userinfo 或其他外部请求。

## 部署配置

发布前由有权限的维护者在 `github-pages` Environment 配置
`CLOUDFLARE_WEB_ANALYTICS_TOKEN` Secret。workflow 仅通过 step `env` 提供，
脚本从 `process.env` 读取并验证；token 不进入 tracked source、`.env`、Vite、
Release ZIP、CLI argument 或日志。配置步骤见 [DEPLOYING](../DEPLOYING.md)。

## 兼容性与验收

本次是向后兼容的新官方 Pages 能力，按 SemVer 使用 MINOR。L11 / L16 / DIRECT /
HALF / VOUT_MODE 数值语义、canonical Raw Word、线上字节、复制、命令参考和
偏好持久化合同不变，不引入额外 npm 依赖或器件 profile。

验收要求包括 overlay 单元/集成测试、纯 Release 负向回归、受控 Cloudflare stub
下的本地 overlay E2E、deployment 合同本地模拟、完整 `npm run verify`、已有视觉
回归，以及桌面/390px、亮暗主题的 Pages 截图逐图检查。实际命令、退出码、测试数、
coverage 与 CI URL 记录在实现 PR，不把本地 smoke 写成真实线上部署证明。
真实 Pages 实体校验和 deterministic remote smoke 在正式发布、部署后执行；
后者继续 stub Cloudflare，只证明 wiring/allowlist，不声明第三方服务健康。
最终上线验收另需干净 Chromium 中无 stub 的真实 beacon GET 与精确 RUM POST
均返回 2xx，且无 CORS/hostname mismatch、未知外部请求或 page error；不得记录
token 或 RUM body。详见 [DEPLOYING](../DEPLOYING.md#发布后真实-cloudflare-analytics-验收)。

遵循 [RELEASING](../RELEASING.md)，不修改、重打或替换任何已发布 tag / Release。
