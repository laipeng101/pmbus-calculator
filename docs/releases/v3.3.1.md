# PMBus Calculator v3.3.1

PATCH release：把已验证的 Pages-only 部署模型固化为可重复执行的 CI/CD 合同，
由 GitHub-hosted runner 自动完成真实 Cloudflare Analytics 验收。

本源码的发行目标为 v3.3.1；在对应稳定 GitHub Release 公开前按待发布处理。
本文描述版本内容；实际发行和部署状态以 GitHub Release / Pages 验收记录为准。

## 交付可靠性

- Pages workflow 复用同一 deploy job 的精确 tag checkout、依赖与 Chromium，
  顺序为 deploy → FINAL `_site` entity verification → deterministic remote smoke
  → **Real Cloudflare Analytics acceptance**，不增加第二套 workflow 或安装成本。
- tracked 的专用 Node 入口观察正式页面实际发出的精确 beacon GET 与 RUM POST，
  要求 2xx 且请求完成，并以 Chromium initiator 绑定 beacon；同时检查 live version、
  production CSP、repository link、CORS、pageerror 与未知外部 origin。
- 最多 3 次独立 context/page 尝试，短 backoff，累计进程硬预算 ≤45s，正常目标 <15s。
  明确配置/CSP/CORS/hostname 错误不重试；缺失请求、阻断、timeout 或 non-2xx
  不能按 PASS 处理。入口不读取 secret、不记录 token、RUM body 或敏感 payload。
- 机器结构测试锁定 post-deploy 顺序、唯一入口与 secret 边界；本地 verify 和
  full PR CI 必须保留 deterministic overlay，且不能运行真实第三方验收。

## 本地隐私与失败语义

维护者可以始终启用 Surge、AdBlock、DNS filter 或其他隐私规则；本地、PR CI、
fresh release 和 deterministic remote smoke 的 Cloudflare 路径继续使用 exact stub。
不需要修改 DNS、代理或 hosts。本机 real check 被明确策略阻止时分类为
`ENVIRONMENT_BLOCKED`，既不是应用失败，也不是 Analytics PASS；权威真实验收
只来自 GitHub-hosted Pages step，未来 Agent 必须遵守 `AGENTS.md` 的稳定规则。

最后一步失败表示 **Pages deployed; real Analytics rollout acceptance failed.**
Release 仍 immutable；不自动回滚、不移动 tag 或替换资产。真实缺陷按后续 PATCH
修复；明确瞬时第三方故障可按 [DEPLOYING](../DEPLOYING.md) 的规则，从同一
immutable tag 重跑完整 Pages workflow，保留全部 provenance 门禁。

## 保留的发行与产品合同

source / clone / Download source ZIP / fork / 普通 build / self-host 与 Release Web ZIP
默认无 Analytics、Cloudflare CSP 域、Pages-only repository link 或 overlay CSS。
两个 Release ZIP 不被 overlay 改写；metadata、checksum、ZIP safety、tag fresh
rebuild byte comparison 和 clean Release smoke 全部通过后，才修改 FINAL `_site`。
Pages 仍只允许精确 Cloudflare beacon GET 与 `/cdn-cgi/rum` POST；应用资源同源，
不添加计算器输入/结果/raw/DIRECT/VOUT_MODE/复制内容的自定义 analytics event。

本次无新产品功能、算法、UI/CSS、canonical raw、持久化或公开用户流程变化，
因此按向后兼容的构建/部署/文档/测试修复使用 PATCH。性能改动只接受有 benchmark
证明的收益；不减少 overlay、Release smoke、Firefox/WebKit、ZIP byte comparison、
entity verification 或 deterministic remote smoke 的覆盖。

完整验收包括 branch verify、精确 merge SHA 的 fresh verify 与既有 visual check、
两次确定性资产比较、clean Release ZIP、immutable Release、全部 Pages 门禁和
hosted real Analytics acceptance。实际命令、exit codes、测试数、coverage、timing
与 CI URL 记录在实现 PR；没有这些线上证据时不声明 fully accepted。

发行资产为 `pmbus-calculator-v3.3.1-web.zip` 与 `SHA256SUMS.txt`；发布流程遵循
[RELEASING](../RELEASING.md)，不修改任何已发布 tag / Release。
