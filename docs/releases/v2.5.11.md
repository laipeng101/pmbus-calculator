# PMBus Calculator v2.5.11

PATCH release — 修复 DIRECT 合法系数组合下的「精确值 → binary64 显示 →
回录」精度折叠（回输显示值会静默改变 payload），并使 Release 下载器对
网络错误的重试真正执行有界退避。

> 2026-08-28 · PATCH（向后兼容 bugfix）· PMBus Rev 1.3 / SMBus 3.0

## 诚实声明：变化的确切性质

1. **DIRECT 精度折叠是可逆性缺陷修复，不是 PMBus 公式或舍入策略变更**。
   Part II §7.4 公式、signed 字段范围、仓库 `Math.round` + signed16 clamp
   合同（DOMAIN_MODEL §2.3）全部不变。变化的是 typed 提交路径的中间层：
   旧路径把用户输入折算成 binary64 再编码，合法系数组合下（如 m=1、b=1、
   R=17，65536 个 Y 中 61108 个受影响）显示值 -1 无法区分精确 -1（raw
   0000）与 -1.00000000000000001 的近似（raw FFFF），回输显示值静默改为
   Y=0 且呈现精确零误差。新路径以用户输入的完整十进制 lexeme 经 BigInt
   精确有理数复现同一舍入合同——本仓库不引入任意精度框架，仅用原生
   BigInt；L11/L16/HALF 数学不受影响。
2. **「encodeDirect(Number) 未发现直接错码」的既有审计边界保持**：本修复
   针对的是「exact rational → binary64/显示 → parse → encode」链路的不可
   逆，不是已证明 `encodeDirect` 对所有 Number 输入都错，也不是 PMBus
   rounding bug。只增加显示位数（`toPrecision(17)` 类方案）无法修复本
   问题——折叠发生在 binary64 本身，不在显示层。
3. **下载器退避是发布可靠性修复，不是已发生事故的响应**。v2.5.10 建立
   的 5 分钟共享预算与文档都承诺网络错误与瞬时 HTTP 同样有界退避，但
   代码中 fetch reject 路径漏掉了退避；本轮使代码与合同一致，并把共享
   deadline 触发的 abort 从可重试错误中区分出来。不存在据此推断的线上
   攻击、事故或数据损坏。
4. **产品稳定公共契约不变**：raw/字节序/复制格式、命令元数据、已持久化
   偏好、README 声明的用户流程均未改变；UNTOUCHED blur 严格 no-op、
   m=0 fail-closed、非 LINEAR fail-closed、0x18 表述等既有合同原样保留。

## Fixed

- **DIRECT 精度折叠回录不保真（P1）**：新增 `src/app/direct-exact.ts`
  （无依赖 BigInt 精确参照：精确解码有理数、真实 binary64 管线的回程
  分析、exact typed 编码、经验证的安全回录文本生成）。typed 提交按
  lexeme 精确编码；折叠状态（`directFidelity`）在警告、量化读数注记与
  计算步骤中标记近似值、精确有理数/十进制（循环小数显式声明无有限精确
  十进制）与回编后果（"不同的请求"）；「物理值」复制返回经独立 exact
  encoder 回验、可安全回录的精确文本，回输后回到原 raw（无法生成验证
  文本时降级为禁用复制并给出原因）。安全普通向量零噪音；raw 0000/FFFF
  切换与系数修改实时重算，无 stale 状态。测试：BigInt 恒等式 oracle、
  可表示值 bit-exact 对照、Math.round tie 语义、全 65536-Y 扫描（
  roundTripSafe 与真实管线等价 + 安全文本全量验证）、固定种子 5000 样本
  fuzz、真实键盘/剪贴板回录 E2E（1280/390/360px、ARIA、无 console
  error）。
- **下载器网络错误退避（P2 发布可靠性）**：fetch reject 与瞬时 HTTP
  走同一退避（`min(2s, 剩余预算)`、计入同一共享预算、每资产仍限 3 次）；
  deadline abort 立即以 code 10 终止；stderr 日志区分五类事件。离线
  测试以注入时钟/睡眠/fetch 证明单次退避、三次耗尽恰好两次退避、退避
  钳制到剩余预算且不越界发起请求、deadline abort 不重试、永久 4xx
  零退避、错误诊断无凭据片段。
