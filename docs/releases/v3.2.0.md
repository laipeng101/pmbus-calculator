# PMBus Calculator v3.2.0

MINOR release：位映射保留完整显示与配置能力，默认展开，并支持记忆收起状态。
本版同时汇总 v3.1.1 之后的 L11、L16、结果上下文、对比度和输入布局修复。

## 位映射与结果布局

- 16 位网格紧接 Raw Word 输入，位于模式参数之前，保留可点击位值、四组
  nibble Hex 和字段图例；桌面默认布局中 Raw、位映射与物理值可见。
- 16 位与 VOUT_MODE 8 位面板都有明确标题和收起/展开按钮。首次使用及没有
  新偏好的旧用户均默认展开；两项状态分别记忆，跨模式和刷新恢复。
- 16 位偏好由 L11/L16/DIRECT/HALF 共享；8 位偏好由独立 VOUT_MODE 与
  L16 内嵌配置器共享。收起不改变 raw、参数、请求来源或复制结果；Hex 和
  语义参数仍可编辑，重新展开即显示当前位值。
- 支持 Enter、Space 和真实触摸；收起后隐藏位按钮退出 Tab 顺序。浏览器
  禁用存储时仍可操作，重新加载恢复默认展开；非法偏好逐字段安全回退。
- 结果旁显示 raw、格式及参数来源。L16 区分标称参考缺失与零，DIRECT
  列出当前系数并提示核对器件数据手册。普通文本对比度与 DIRECT 系数
  输入对齐、可访问标签同步完善。

## 数值与状态修复

- **L11 自动指数边界**：候选集包含每个指数的合法尾数边界，等误差时
  选择较小的指数绝对值。`1023.5 → 03FF`（N=0，Y=1023）与
  `-1025 → 0400`（N=0，Y=-1024）遵循已有规则，并如实显示量化误差。
- **L11 Auto-N 请求来源**：切换自动/锁定指数保留真实请求。只输入 raw
  时不凭空创造请求；锁定 N=1 后输入 `1.25`，再启用 Auto-N 会按原请求
  编为 `F005`，而不是把当前表示值 `2` 当作新请求。显式零仍是有效请求。
- **L16 复制可用性**：非 LINEAR、缺少标称参考等没有物理结果的状态禁用
  物理值复制，并给出可访问原因；真实零值保持可复制，不再把缺失值视作零。

## 兼容性与范围

新增能力是可选的面板收起记忆，因此按 SemVer 使用 MINOR。原有主题、模式与
复制偏好继续读取；canonical 16-bit Raw Word、线上字节顺序、命令参考只读
合同保持。L11 边界修复恢复已定义的等误差选择规则，未另立舍入策略。
v3.1.1 的 DIRECT 显示文本回录修复包含在本版中，不重复列为新增修复。

面板切片未修改算法；本发行范围包含此前已合并的 L11 算法修复及其 golden
回归。规范基线仍为 PMBus 1.3/1.3.1 与 SMBus 3.0，不新增器件 profile。
移动端优先显示 Raw 和位映射，其余参数可滚动访问；不承诺所有控件都在首屏。
Playwright WebKit smoke 不等于 Safari 一致性证明。

## 验收与发行

验收覆盖完整单测/coverage、桌面、真实移动触摸、Firefox/WebKit 核心 smoke、
本地生产 smoke 与独立视觉回归；26 张原有位映射相关基线逐图审查，新增桌面
16 位与移动 8 位收起场景，命令参考基线不受本次面板布局影响。
