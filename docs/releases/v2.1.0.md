# PMBus Calculator v2.1.0

MINOR release — M36 结果优先响应式布局 + 确定性视觉基线治理。

## 概述

v2.1.0 向后兼容地改变信息层级与交互呈现，不修改任何 L11 / L16 / DIRECT / HALF /
PEC 算法、舍入、饱和、字节序、持久化数据结构或命令元数据语义，也不修改 read-only
legacy `pmbus-calculator.html`。

默认信息顺序变为：

```text
Header → 模式切换 → 物理结果摘要 → 当前模式输入/输出工具 → 命令参考 → 调试抽屉
```

## 变更

### 结果优先布局

- 将 `ResultInspector` 按职责拆分为：
  - `ResultSummary`：唯一结果面板与 live region，位于模式切换之后、主 workspace 之前；
    保留 `aria-label="结果面板"`、`data-testid="result-panel"/"result-tile"/"result-value"`。
  - `ResultDetails`：workspace 辅助栏，包含原始 Hex、LE/BE、量化误差、复制 toolbar、
    warnings 与计算过程 disclosure。
- 桌面使用紧凑横向 grid（数值与公式主次分明），移动端自然堆叠；长值不截断/缩放/隐藏，
  公式仅在 `.math-scroll` 容器内横向滚动。
- 四模式切换时结果卡顶边稳定（实测差异 ≤ 2 px）。

### 计算过程 disclosure

- `CalculationSteps` 保留 view-model 单一数据源与全部 steps，默认折叠为原生
  `<details>/<summary>`；summary 文案为“计算过程（N 步）”。
- 展开后继续显示字段 / 公式 / 中间值 / 结果 / 提示结构、KaTeX 与纯文本 fallback。
- 键盘 Enter/Space 可操作，有可见 focus-visible，展开/收起不修改计算状态。

### 命令参考降级

- `CommandReference` 移动至主 workspace 之后，继续默认折叠、只读、13 行、无副作用。
- 折叠状态下只显示按钮；原说明移入展开内容顶部。

### 视觉基线治理

- 生产代码继续通过 `package.json → vite.config.ts → __APP_VERSION__ → AppHeader` 显示真实版本。
- 仅 `tests/e2e/visual.spec.ts` 的 scene helper 在截图前断言真实 badge 为 SemVer 形状，
  再规范化为 `v0.0.0-visual`；不 mask，且该逻辑不进入 `src/` 或生产 bundle。
- `release.spec.ts` / `deployment.spec.ts` 继续断言真实 `v2.1.0`。
