# PMBus Calculator v2.6.2

PATCH release：审计修复——发布完整性 fail-closed、DIRECT 词素边界、帮助系统
SC 1.4.13 可悬停合同、VOUT_MODE radio 键盘合同与内嵌禁用原因可见化。

**本版本不改变任何 PMBus 数据格式的数学语义**：LINEAR11/LINEAR16/DIRECT/HALF
的表示关系、舍入策略、signed-zero 与特殊值合同、provenance 与资源边界全部
不变。全部受保护算法（`decodeLinear11`/`encodeLinear11`/`findBestLinear11`/
`decodeLinear16`/`encodeLinear16`/`decodeDirect`/`encodeDirect`/`decodeHalf`/
`encodeHalf`/`parseVoutMode`/`calculatePEC`）零变更；DIRECT 修复仅作用于
词素归一化与拒绝边界（BigInt 之前的 O(n) 尾零剥离 + 有效移位下溢判定），
编码/解码/舍入路径未触碰。

## 变更范围

1. **已发布 Release 不可变性 fail-closed 验证（P1）**：`release-assets-verify`
   在 published 模式下要求 Release 元数据 `immutable === true`（缺失/false/
   非布尔一律 exit 3），draft 模式豁免；`verify-downloaded-assets` 经共享
   边界继承同一门禁；Pages workflow 合同测试钉住 published 模式 metadata →
   download → verify → extract → deploy 步骤顺序。`docs/RELEASING.md` 新增
   历史 mutable Release 操作停止策略（v2.5.13+ immutable、v2.5.12- mutable、
   历史 mutable 发布绝不能成为手动部署/回滚目标、旧 tag/Release 永不删除/
   重建/移动、新代码不回溯改动旧 tag 的工作流与脚本）。
2. **DIRECT 尾零补偿科学计数法精确提交（P2-A）**：审计最小向量
   `1`+501×`0`+`e-501`（507 字符，Number 恰为 1）此前被句法移位边界按
   `shift-out-of-range` 拒绝——UI 判 valid、reducer 静默 no-op、无任何错误。
   现在尾零剥离前置于 BigInt 构造，下溢边界改为按有效移位判定（下限
   `-max(500, raw.length + 323)`，323 由 binary64 最小次正规数推导），保证
   任何 classify-valid 词素都不会被静默丢弃；4096 原始长度门禁与「trim 前
   计数」不变。新增 golden 矩阵（e-500/e-501/e-502、±符号、部分补偿、深位
   golden、fail-closed 钉子、4096 字符补偿向量）、reducer provenance 与
   E2E 提交断言（raw 0x0007 → 0x0001）。
3. **控件 tooltip 可悬停驻留（P2-B，WCAG 2.2 SC 1.4.13）**：指针离开触发器
   进入 150ms 确定性宽限，移入浮层或回到触发器取消关闭，离开两者后才关闭；
   Escape / blur / 外点关闭、click 恰好一次、触屏零劫持、全局单开合同不变。
   surface pointerenter 只取消定时器不写状态，焦点来源不被 hover 翻转。
4. **VOUT_MODE radio 键盘合同（P2-C，ARIA APG）**：两组 `role=radiogroup`
   实现 roving tabindex + 方向键行走（Right/Down 下一项、Left/Up 上一项、
   循环、跳过 VID disabled 项），焦点到达即选择并复用 click 幂等守卫；
   选中项 disabled 的非法字节按首个可用项兜底 tab stop。独立页与 L16 内嵌
   同样生效；纯函数决策在 `src/app/radio-navigation.ts`（20 条单测）。
5. **L16 内嵌 bits[6:5] 禁用原因浮层外可见（P2-D）**：新增可见原因行
   `vout-bits65-disabled-reason`，linked/非 LINEAR 措辞单一来源
   （`src/app/vout-mode-formats.ts`），经 `aria-describedby` 关联到 bit5/
   bit6 按钮；tooltip 与 aria-label 合同不变。
6. **死代码清理（P3）**：删除零生产消费者的 `src/app/focus-navigation.ts`
   及其同名测试（仅自引用，rg/import 图证明）。
7. **文档**：`docs/UI_CONVENTIONS.md` §7「移开即消失」改写为 SC 1.4.13
   可悬停/可驻留/可关闭合同；§7 禁用控件与 §14 补 aria-describedby 关联与
   单一来源。

## 诚实陈述

1. **数学语义零变更**：受保护算法与其 golden case 未触碰；DIRECT 边界修复
   只把「classify-valid 却被拒绝」的词素放行到既有精确路径，已接受词素的
   编码结果不变（既有 golden 全部保持通过）。
2. **视觉基线变化即本版本的功能面**：L16 三个桌面场景（desktop dark
   LINEAR16 / desktop light L16 / desktop dark L16 stress）因新增可见禁用
   原因行更新，基线字节 112916→115176 / 110009→112340 / 108006→112682；
   逐图审查确认唯一差异即新原因行及其下移内容，其余 25 张基线零变化。
3. **部署链前提**：本版本发布后 Pages 仅部署 immutable Release 资产；
   v2.6.2 起验证脚本对 published 模式强制 `immutable === true`（P1），
   历史 mutable Release 的操作停止策略见 `docs/RELEASING.md`。
