# PMBus Calculator v2.6.7

PATCH release：VOUT_MODE 独立术语行 `N` 触发器点击目标修复（P2，可访问性）。
全部受保护算法（`decode/encodeLinear11`、`findBestLinear11`、`decodeLinear16`、
`encodeLinear16`、`decode/encodeDirect`、`decode/encodeHalf`、`parseVoutMode`、
`calculatePEC`、`encodeUlinear16`、`encodeSlinear16`）零变更；raw 单一真值、
provenance、L16 字节序、持久化格式、copy 合同与命令元数据零变更；
`pmbus-calculator.html` 离线归档零修改。

## 变更范围

1. **VOUT_MODE 独立术语行 hitbox（P2）**：独立 VOUT_MODE 页术语行中
   exponent（`N`）触发按钮实测 `11.5625×24 px`（四个 viewport 一致），违反
   `docs/UI_CONVENTIONS.md` §10「点击目标至少 24×24px」合同。根因是全局
   `.term-trigger` 为零 padding 的 `inline` 元素，单字符术语在
   `.vout-term-row`（flex 行）内形成过窄命中区。修复为 scoped 规则
   `.vout-term-row .term-trigger { min-inline-size/min-block-size: 24px;
text-align: center }`，N 按钮现为精确 `24×24 px`；其余三个按钮
   （VOUT_MODE / Absolute-Relative / LINEAR）尺寸不变（实测值，非合同锁定）。
2. **作用域边界**：规则仅作用于 `.vout-term-row` 内的触发器（非 embedded 渲染
   的独立行，`.vout-term-row` 全仓仅此一处）；页头、正文、公式说明、结果区、
   命令参考与配置摘要中的句内术语触发器不受影响，不放大。
3. **回归与视觉基线**：`terminology-popover.spec.ts` 新增三 viewport
   （360×800 / 390×844 / 1440×900）几何回归——术语行全部触发器 ≥24×24、
   两两不重叠、水平方向完全位于 viewport 内（垂直方向页面可正常滚动）、
   无 body 横向溢出；
   `mobile-contract.spec.ts` 新增 exponent 触发器真实 touchscreen tap 打开/
   触摸外部关闭路径。四张 VOUT_MODE 视觉基线（desktop dark/light、
   desktop light 术语气泡打开、mobile 390）更新，逐图成对审查确认变化全部
   限于术语行 N 区域及其换行级联（mobile 端术语行由 2 行换行为 3 行，
   无裁切、无重叠）。
