# PMBus Calculator v2.6.3

PATCH release（test-only）：修正 v2.6.2 正式站验收测试的 DIRECT 系数错误。

**应用代码与 dist 资产相对 v2.6.2 零差异**：受保护算法、DIRECT 词素边界、
帮助系统、a11y 合同全部不变；zip 中唯一的内容性差异是构建注入的版本字符串
（v2.6.2 → v2.6.3）。

## 变更范围

1. **验收测试系数修正**：v2.6.2 发布 event 的 Pages workflow remote smoke
   中，「DIRECT 尾零补偿科学计数法向量提交为 raw 0001」用例误用 fidelity
   组系数 (m=1, b=1, R=17)。该组下 DIRECT 的 Y（16 位有符号）无法表示
   V=1（需要 Y=10^17−1），应用按既有溢出合同饱和编码为 Y=32767
   （raw 0x7FFF），用例因此失败（3 次重试一致）。
2. **根因归属（诚实陈述）**：这是验收测试抄错系数组——正确系数来自
   direct-fidelity v2.6.2 边界用例的 (m=1, b=0, R=0)（该用例在同一构建的
   CI e2e 中通过）。应用行为正确：饱和编码正是 DIRECT 溢出的既有合同。
   修正后用例对正式站实测通过（raw 0001，无字段错误，量化面板 kind=ok）。
3. **其余 7 条 deployment 验收在 v2.6.2 发布 smoke 中已通过**：版本徽章、
   同源资源、390 无溢出、L11 闭环、tooltip 可悬停驻留、VOUT_MODE radio
   方向键、L16 bits[6:5] 可见禁用原因。

## 诚实陈述

1. v2.6.2 Release 保持已发布且不可变（不删除、不重建、不移动 tag）；其
   workflow remote smoke 的失败由本版本修正并留档，重跑 v2.6.2 的
   workflow 不能也未被尝试改变历史。
2. 本版本的应用 dist 与 v2.6.2 的差异仅为版本字符串注入；正式站验收
   （8/8）在 v2.6.3 发布 event 的 workflow 中重新完整运行并通过。
