# PMBus Calculator v2.3.0

MINOR release — M38 独立 VOUT_MODE 计算器与标准 LINEAR16 语义。

> 2026-08-26 · MINOR（向后兼容）· PMBus Rev 1.3 / SMBus 3.0

本版本新增第五个 **VOUT_MODE** 模式（8-bit 字节配置器），并把 LINEAR16 payload 拆分为
标准 `ULINEAR16`（`X = Y_u × 2^N`）与 `SLINEAR16 offset`（`X_offset = Y_s × 2^N`）两种
语义，同时把相对 LINEAR 的比值解码补全为 `X = V_NOM × R`。L11/DIRECT/HALF 的计算语义、
舍入/饱和、字节序与命令参考只读行为均未改变。

## 新增交互

- **独立 VOUT_MODE 计算器**：第五个 tab / `Ctrl+5`；8-bit 双 nibble 交互位网格
  （bit7 Absolute/Relative、bits[6:5] format、bits[4:0] parameter），raw 位/Hex 编辑
  lossless（可构造 `0xA0`/`0x41`/`0xE1`），语义控件 canonicalize（VID 强制 Absolute、
  DIRECT/Half 参数强制 0），`Normalize` 显式规范化；legend 分区着色与双语说明。
- **LINEAR16 payload 选择器**：`ULINEAR16`（无符号 `Y_u`）与 `SLINEAR16 offset`
  （二补码 `Y_s`）；relative ULINEAR16 提供 nominal VOUT_COMMAND 输入后按
  `X = V_NOM × R` 计算，未提供时只显示比值。
- **L16 共享 VOUT_MODE**：bits[6:5] 锁定 `00`（LINEAR），bit7 / N 可编辑；共享字节非
  LINEAR 时回退 `0x18`（`fallback-default`）并显示 linked/fallback 双语徽标，不静默改写字节。
- **固定 0x 前缀 Hex 输入**：前缀在输入框外，输入值只有十六进制数字；粘贴 `0x18`/`0X18`
  归一化为 `18`。

## 规范结论（M38）

- `format` 只取 `(byte >> 5) & 0x03`；旧 `(byte >> 5) & 0x07` 把 bit7 混入 format 是位域错误。
- bit7 只作用于 §8.5 的 8 个输出电压相关命令；SLINEAR16 offset 的 bit7 不参与
  `X_offset = Y_s × 2^N`，相对 + 有符号比例是伪标准组合，不提供。
- Relative 不适用于 VID：`0xA0..0xBF` 是非法组合；`format` 非 `00` 且非绝对时不得标成“相对 LINEAR”。
- 官方 Relative 示例 `0x96` + raw `0x0466`（1126）→ `R = 1.099609375 = 109.9609375%`；
  `V_NOM = 3.3` 时 `X = 3.6287109375 V`。SLINEAR16 N=-8 时 raw `0x0100` → `+1 V`、
  `0xFF00` → `-1 V`；同一 raw `0xFF00` 在 ULINEAR16 下为 `255 V`。
