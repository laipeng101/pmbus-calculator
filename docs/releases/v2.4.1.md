# PMBus Calculator v2.4.1

PATCH release — 位字段网格卡片内溢出修复（v2.4.0 回归）+ 视觉基线审查流程约定。

> 2026-08-27 · PATCH（向后兼容）· PMBus Rev 1.3 / SMBus 3.0

v2.4.0 的共享位字段网格在桌面双栏与移动端把位格渲染到卡片边框之外。本版本修正
网格收缩行为，使 8/16 位编辑器在全部视口下完整落在宿主卡片内；并新增流程约定：
视觉重构 PR 更新基线时必须附新旧基线 diff 审查记录，防止"以新渲染结果直接为新基线"。

## Fixed

- **位字段网格卡片内溢出（v2.4.0 回归）**：16 位 4 列 auto 轨道最小需求 714px 超出
  卡片内容宽 618px，居中对齐使溢出对称分布在卡片两侧（1024–1151px 双栏布局达
  112px/侧）；8 位两列在 390/360px 移动端同样溢出。根因是 M39 网格重构放大了位格
  尺寸而 `auto` 轨道不收缩。
- 修复方式（纯 CSS，无 DOM/语义变化）：网格轨道改为可收缩 `minmax(0, 设计宽)`
  （regular 10.875rem、compact 6.25rem），建立 nibble→bits→button→cell 收缩链；
  16 位 4 列断点从 1024px 修正到 1152px 对齐双栏工作区实际列宽。

## 防线修复

- 新增 E2E 回归测试"位格始终落在宿主卡片内容盒内"：页面级 scrollWidth 断言拦不住
  容器内居中溢出，新测试直接断言位格几何 ⊆ 卡片内容盒（已验证对 bug 状态失败、
  修复后通过）。
- 流程约定：视觉重构 PR 更新基线时必须附新旧基线 diff 审查记录
  （先记录失败场景为预期影响面 → 新旧 PNG 成对对比 → 核对更新集合与影响面吻合），
  落地于 REPOSITORY_HYGIENE 第 3 节第 10 条、UI_CONVENTIONS 第 11 节、
  AGENTS.md PR checklist 与 PR 模板 UI/visual evidence 字段。
