# PMBus Calculator v2.0.0

MAJOR release — 产品重新定位为 PMBus 数值格式计算器；移除命令选择器与 preset 自动应用；
L11/L16 饱和与状态语义修复；命令参考 note 渲染；样式与文档一致性收尾。

## 概述

v2.0.0 是自 v1.1.11 以来的第一个 MAJOR 版本，也是本仓库发布链路简化（可重新执行的打包步骤、
CI 并行化、文档纠偏）之后的首个正式发布。产品范围明确为 **PMBus 数值格式计算器**：只做
LINEAR11 / LINEAR16（VOUT）/ DIRECT / IEEE 754 binary16 的双向数值换算，不声明完整
PMBus 1.5 协议一致性，不覆盖总线传输、命令执行、设备 Profile、PMBus 1.5 安全扩展与 Part IV。

## Breaking changes 与迁移方式

- **移除命令选择器（CommandPicker）与其自动修改计算状态的行为**：选择命令不再切换模式、
  不注入参数、不重写 raw，也不会自动填入 VOUT_MODE 或 DIRECT 系数。
  - 迁移：需要 preset 的旧工作流改用手动输入；数据格式由器件数据手册或 VOUT_MODE 决定。
- **命令参考降级为默认折叠的只读面板**：任何命令行都没有选中态、没有搜索框、没有预设入口。
  - 迁移：命令码、事务、数据类型、单位、格式来源与规范章节在只读命令参考中查阅即可。
- **L16 状态约束**：relative LINEAR、VID、DIRECT、IEEE Half VOUT_MODE 下不再产生任何
  LINEAR16 电压结果（reducer 层直接拒绝编码，不再只是隐藏 UI 输入）。
- **L11 饱和语义**：autoN=false（锁定 N）时按该 N 的 Y=-1024..1023 范围判断饱和并显示
  warning；Y=1023/-1024 边界编码始终合法。

## 变更

### 发布链路与工程

- `release:prepare-assets` 恢复为可重新执行的打包步骤；删除长期 release lock、事务
  journal、进程监督与 zero-skip 聚合 runner，发布生成器测试纳入普通单测。
- CI 并行化：`quality` / `e2e` / `compatibility` + 轻量 `check` 聚合（required check）。
- 文档纠偏：AGENTS.md / ROADMAP / RELEASING 只保留长期约束与发布步骤。

### 产品与领域语义

- 产品定位改为 **PMBus 数值格式计算器**；不声明完整 PMBus 1.5 一致性。
- VOUT_MODE 位域按 Part II §8.3 修正（bit7=absolute/relative、bits[6:5]=mode、bits[4:0]=param）。
- L16 只在 absolute LINEAR 下给出电压结果、V、N、2^N 与可表示电压范围；relative LINEAR
  仅解释指数/比值语义；VID/DIRECT/IEEE Half 不生成虚假 LINEAR16 V/N/range/result。
- L11 饱和按 autoN/锁定 N 分别判断；真实 clamp 才显示 saturation warning。
- 四模式统一计算过程展示（calculation-steps + CalculationSteps 组件）。
- 命令参考渲染 metadata note：STATUS_WORD 与 READ_EIN 的规范说明可见；无任何副作用。

### UI / 样式

- 清理本批新增的静态 inline style，迁移到既有 CSS/class 体系（tokens.css、legacy HTML class）。

### 文档

- `docs/MIGRATION_MATRIX.md`：Pages 根路径 200（产品入口），仅 legacy `/pmbus-calculator.html`
  为 404；legacy 文案为“保留仓库内离线兼容用途，只接受必要纠偏，不再作为当前 Pages 产品入口”。
- `docs/DEPLOYING.md`：“命令选择器”改为“只读命令参考”。
- README / README_zh-CN / DOMAIN_MODEL / specifications manifest / 部署与发布文档范围一致。

## 已知限制

- READ_EIN 权威字节数选择：需要目标器件数据手册，blocked。
- DIRECT device-datasheet profiles：需要真实器件数据手册，blocked。
- PMBus 新版规范升级：独立工作，当前不得自动开展。
- 本版本不覆盖：总线传输、命令执行、设备 Profile、PMBus 1.5 安全扩展与 Part IV。
