# PMBus Calculator v3.4.1

PATCH release：修复 v3.4.0 发布后暴露的 hosted 真实 Analytics 验收缺陷——Pages
post-deploy verifier 与 M43 版本徽标（`App vX.Y.Z`）合同不一致，导致 Pages 部署
成功但 rollout acceptance 确定性失败（`VERSION_MISMATCH`）。本次不改变产品行为。

本源码的发行目标为 v3.4.1；在对应稳定 GitHub Release 公开前按待发布处理。
本文描述版本内容；实际发行和部署状态以 GitHub Release / Pages 验收记录为准。

## 缺陷与修复

- v3.4.0 按 M43 设计把版本徽标从 `vX.Y.Z` 改为 `App vX.Y.Z`，并同步了
  deployment/release/visual E2E；但 `scripts/verify-live-analytics.mjs` 仍把徽标
  完整展示文本与稳定 tag 直接比较，使 hosted real Analytics acceptance 在任何部署上
  都确定性失败为 `VERSION_MISMATCH`（非 retryable）。
- verifier 现在要求页面中恰好一个 `[data-testid="version-badge"]`，其完整 trim 文本
  严格匹配 `App vX.Y.Z`，再复用 `release-artifact-contract.mjs` 的
  `isPlainSemver` / `stableTag` 构造 canonical tag 与期望 Release/tag 精确比较。
- fail-closed：缺失徽标、malformed 文本、多个徽标、多个/歧义版本 token 一律
  `VERSION_MISMATCH`；不使用“任意位置找到一个 semver 即接受”的宽松匹配。
- beacon、RUM、CORS、unexpected origin 与 pageError 门禁完全保留。

## 回归测试

- 正常解析 `App vX.Y.Z`（含首尾空白）。
- 期望/实际版本不一致仍确定性失败。
- 缺失徽标、重复徽标、malformed 与多 token 歧义 fail-closed。

## 保留的发行与产品合同

- 版本徽标继续按 M43 显示 `App vX.Y.Z`；产品、算法、canonical raw、复制、持久化与
  公开用户流程不变。
- Release / Pages 分发边界不变：immutable Release 资产、tag fresh rebuild 字节比较、
  clean Release smoke、FINAL `_site` overlay 与全部 provenance 门禁保留。
- 本次为向后兼容 PATCH。

## 验收

v3.4.1 只有最后的 GitHub-hosted 真实 Analytics acceptance 成功后才声明完整 rollout
成功。实际命令、exit codes、测试数、coverage、timing 与 CI URL 记录在发布准备 PR。

发行资产为 `pmbus-calculator-v3.4.1-web.zip` 与 `SHA256SUMS.txt`；发布流程遵循
[RELEASING](../RELEASING.md)，不修改任何已发布 tag / Release。
