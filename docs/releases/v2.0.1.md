# PMBus Calculator v2.0.1

PATCH release — 修复 v2.0.0 发布后评审发现的 2 个 P1 实质问题与 2 个验收覆盖缺口。

## 概述

v2.0.1 不改变 v2.0.0 的计算语义与发布链路，只做：线上产品名称统一、构建时版本徽标、
legacy 离线归档文件的领域语义对齐、命令参考视觉快照覆盖补强。v2.0.0 的 tag/Release/资产保持不变。

## 修复

### P1：线上产品名称重新定位

- 页面标题（AppHeader）：`PMBus 协议计算器` → `PMBus 数值格式计算器`。
- 浏览器标题（index.html）：`PMBus 数值格式计算器 — LINEAR11 / LINEAR16 / DIRECT / binary16`。
- 副标题与范围说明：`LINEAR11 / LINEAR16 / DIRECT / binary16` + `数值格式换算，不实现完整 PMBus/SMBus 协议栈`。

### P1：legacy HTML 算法与说明对齐（离线兼容文件）

- `parseVoutMode`：`(byte >> 5) & 0x07` → `& 0x03`，新增 bit7 `isRelative`（Part II §8.3）。
- `checkSpecial`：Y=1023 / Y=-1024 不再被标记为饱和/溢出边界（合法边界编码）。
- STATUS_WORD 说明补充“通常为 Read Word；特殊写入 0x0100 仅用于清除 UNKNOWN 位”。
- READ_EIN 说明展示 §18.13 6 字节 vs Appendix I Table 31 5 字节的规范冲突。
- 下拉引用 `Part II 18.14` → `Part II 18.13`。
- 内置自检新增 0x98/0x20/0x40/0x60/0xE0 VOUT_MODE、L11 边界、STATUS_WORD/READ_EIN 断言；
  新增 `tests/legacy-html-contract.test.ts` 在 CI 中守护。

### P2：构建时版本徽标

- `vite.config.ts` 从 package.json 注入 `__APP_VERSION__`，页面显示只读版本徽标（`v2.0.1`），
  不再手工维护版本文本。
- release smoke 与 deployment smoke 增加版本徽标断言（自动与 package.json 一致）。

### P2：命令参考视觉快照覆盖表格

- 视觉测试改为对 `.command-ref-table-shell` 元素截图（light/dark），真正覆盖表格与“说明”列。

## 已知限制

- READ_EIN 权威字节数选择：需要目标器件数据手册，blocked。
- DIRECT device-datasheet profiles：需要真实器件数据手册，blocked。
- PMBus 新版规范升级：独立工作，当前不得自动开展。
- 本版本不覆盖：总线传输、命令执行、设备 Profile、PMBus 1.5 安全扩展与 Part IV。
