# PMBus Calculator v1.1.3

PATCH 修复发行：围绕结果展示、交互打磨与发行来源加固，修正 v1.1.2 已确认的长结果溢出、公式排版、量化误差语义和工具栏组织问题。

发布渠道：GitHub Release（不发布 npm 包）。

## Fixed

- **长结果值**：结果主数值使用等宽 + `tabular-nums`，按内容长度采用可预测字号档位；不省略、不换行、不 `scale()`；结果 tile 增加 `min-width:0` 和 overflow 防护。
- **HALF 公式**：headline 已显示最终物理值时，展开式不再重复最终长小数；normal 展示 `s / E / F` 字段摘要与展开式；zero、subnormal、±Infinity、NaN 保留各自正确语义。
- **DIRECT LaTeX**：负指数渲染为 `10^{-12}`，不再出现 `10^{(-12)}`；`plainText` 与 C 宏注释保持既有兼容格式。
- **量化误差**：文案改为“量化误差”；`ok`/`warn`/`error` 分别映射 success/warning/danger，误差正负号只表示方向。
- **复制工具栏**：Hex 主按钮动态显示 `Hex（LE）` / `Hex（BE）`；偏好区拆为“Hex 格式”和“Hex 复制顺序”两个语义分组，标签与控件同组换行。
- **文案与术语**：统一为 `PMBus 命令`、`物理值`、`小端序（LE）`、`大端序（BE）`、`V（16 位无符号，0～65535）`、`Y（16 位有符号，−32768～32767）`、`IEEE 754 binary16（半精度）`。
- **交互收敛**：BitGrid 移除 hover 放大；InfoPanel 与图例改用设计 token；暗色滚动条统一为细滚动条并覆盖 Firefox/WebKit；动效 120～180ms，尊重 `prefers-reduced-motion`。
- **回归保护**：新增 L11/L16/DIRECT/HALF 非零应力 golden cases、HALF 边界分类、自适应字号、量化误差颜色语义、viewport 几何断言和亮暗/移动端 visual snapshot。

## Install / Run

```bash
npm ci
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 生产构建到 dist/
npm run preview  # 预览 dist/
```

## Build Artifact

`pmbus-calculator-v1.1.3-web.zip` 包含 `dist/` 的可部署静态内容。校验：

```bash
sha256sum -c SHA256SUMS.txt
```

## Known Limitations

- 自动化浏览器验证仍以桌面和移动 Chromium 为主。
- visual snapshot 为 darwin 基线，CI 默认不运行 `test:e2e:visual`。
- 当前规范基线为 PMBus Rev 1.3，不声明 PMBus 1.5 兼容。
