# PMBus Calculator v3.1.0

MINOR release：Hex `+1`/`−1` 步进器新能力 + 输入可发现性修复。全部受保护
算法（`decode/encodeLinear11`、`findBestLinear11`、`decodeLinear16`、
`encodeLinear16`、`decode/encodeDirect`、`decode/encodeHalf`、`parseVoutMode`、
`calculatePEC`、`encodeUlinear16`、`encodeSlinear16`）、canonical Raw Word
领域模型（v3.0.0）、VOUT_MODE 位域、复制格式、持久化偏好零变更。

## 为什么是 MINOR（向后兼容新能力）

RELEASING「稳定公共契约」五项全部不变：计算与舍入语义、raw word/字节序/
复制格式、命令元数据行为、已持久化偏好、README 声明的用户流程。本版新增
能力并修复输入可供性，不改变任何既有用户流程：

1. **Hex 步进器**：Raw Word（16 位）与 VOUT_MODE（8 位）Hex 输入框内嵌
   `+1`/`−1` 按钮——新交互，走既有 `raw/set-from-hex` /
   `vout-mode/set-byte` commit 路径，不创建第二套 raw/字节事实源。
2. **可编辑可供性**：真实可编辑字段与只读展示框在静止态（亮/暗）视觉
   可区分——纯呈现层修复，DOM 结构与状态合同不变。
3. **Raw Word ↔ bit 网格间距**：编辑 shell 与位网格之间建立 ≥8px 稳定
   净间距——scoped 布局修复。

## 步进器合同

- 范围由 `maxDigits` 推导：16 位 `0x0000..0xFFFF`、8 位 `0x00..0xFF`；
  边界处对应按钮真实 `disabled`，**永不回绕**（FFFF +1 无效果、保持 FFFF）。
- 输出恒为大写、固定位宽、补零（`00FE +1 → 00FF`、`FE +1 → FF`）。
- 基值选择：合法草稿以草稿解析值为基值；空/非法过渡草稿以最后 committed
  值为基值，步进后草稿被规范合法文本替换、字段错误清除、经既有
  `onCommit` 提交。
- 每次点击 / Enter / Space 激活恰好一次提交；步进按钮在 `pointerdown`/
  `mousedown` 阶段 `preventDefault` 保持输入框焦点——真实浏览器的
  blur/click 竞态不会发生，步进后编辑事务被消费，blur 仍是严格 no-op
  （组件单测锁定「步进后 blur 不二次提交」）。
- 键盘可达：可 Tab、Enter/Space 激活、focus-visible 可见；可访问名带字段
  上下文（「Raw Word（16 位原始字）增加 1 / 减少 1」）；输入框的
  ArrowUp/ArrowDown 文本编辑语义不被劫持。
- 触屏：coarse pointer 下步进区 ≥44px 宽、单按钮 ≥28px 高、shell 约 66px；
  桌面（fine pointer）`+`/`−` 横向并排、shell 高度与普通输入框一致（不推高
  M36/M39 桌面布局预算）、步进目标 ≥24×24（WCAG 2.2 SC 2.5.8）；真实
  touchscreen tap 驱动同一 canonical state（mobile-contract 套件锁定）。

## 验收向量（golden）

- Raw Word：`0000 +1 → 0001`、`0001 −1 → 0000`、`FFFF +1` disabled、
  `0000 −1` disabled、`00FE +1 → 00FF`（空草稿从 committed 基值）。
- VOUT_MODE：`00 +1 → 01`、`FF +1` disabled、`00 −1` disabled。
- 步进同步：raw 0001 时 bit0=1、物理值 `1`、辅助结果 Raw Word `0x0001`、
  Wire `01 00`、MSB-first `00 01` 全部同源。
- 几何：Raw 编辑 shell 底边 → bit 网格顶边净间距 360/390/1280 全部
  `>= 8px`（实测 12px）；步进目标 `>= 24×24`。

## 诚实陈述

1. 视觉基线 28 条中 26 条按新旧成对审查更新，2 条（command-reference
   light/dark，只读页无输入控件）确认无需更新。变化恰好落在四类预期：
   可编辑输入获得 token 迁移后的井/边框、hex 字段获得 0x 前缀与步进器、
   Raw Word 与 bit 网格间距、L16-stress 桌面场景因 fill 自动滚动不再触发
   而从滚动位落入页顶（内容逐项一致）。逐对理由记录在 PR 描述。
2. 步进器不提供 press-and-hold 连发（任务合同允许的省略，降低触屏误触
   风险）；如需连发，后续以独立能力评估。
3. 本版不含任何器件 profile、算法或规范语义变更；不声明 PMBus 1.5。
