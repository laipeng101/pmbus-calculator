# PMBus Calculator v1.1.6

PATCH release — 发布管线加固、合同完整性与精确运行时下限。

## 概述

v1.1.6 是 M25 里程碑发布，在 v1.1.5 基础上修复发行资产生成器、发布合同和运行时下限合同中的已验证缺口。不涉及 PMBus 算法、命令元数据或 UI 行为变更。

## 修复

### 发行资产生成器 fail-closed 与事务式发布

- `walkDist` 显式分类所有 Dirent 类型（symlink、FIFO、socket、device 均报错），禁止静默跳过任何目录项。
- 路径校验使用分量级判断：拒绝 `..`、`node_modules`、`src`、`.map`、控制字符。不使用简单 substring 误判。
- 提交固定 `scripts/_zip_helper.py` 替代动态生成临时脚本；Python executable 可注入（`PYTHON3` 环境变量）。
- checksum 反向验证使用 Node `crypto`（不依赖平台 shell `shasum`）。
- 事务式发布：`.release-staging/<unique-run-id>/` 唯一 staging → 验证 → 发布到 `release-output/`。`--force` 使用 backup/rollback 保护旧资产对。
- 并发锁（`.release-staging.lock`）防止并发运行破坏资产。
- 零遗留 `.cache/zip-*` 临时文件。
- 新增 `tests/prepare-release-assets.test.ts`（19 测试）。

### 发布合同完整性

- 结构化 CHANGELOG 解析：忽略 fenced code block 内伪标题；恰好一个 `## [Unreleased]`；必须是第一个 release-level heading；当前版本是其后的第一个 dated section；重复/缺失/乱序全部失败。
- `readContract` 现在读取 RELEASING.md 内容和 generator 共享合同导入检查。
- 删除 `main()` 中 RELEASING 旁路追加逻辑——纯函数、fixture 和 CLI 走同一 read→validate 路径。
- 新增 10 个 CHANGELOG 结构测试和 9 个 integration fixture 测试。

### 共享发行资产合同

- 新增 `scripts/release-artifact-contract.mjs`：集中定义 `assetZipName`、`assetSumsName`、`PAGES_ZIP_TEMPLATE`、`validateZipEntry` 等。`prepare-release-assets` 和 `check-release-contract` 均从该模块导入，消除多处重复命名模板。

### Node 精确运行时下限

- engines 从 `>=22 <23` 收紧为 `>=22.20.0 <23`（Node 24 保持 `>=24.0.0 <25`）。
- `@types/node` 从 `^22.20.1` 改为精确 `22.20.1`（防止自动漂移到更高 minor）。
- CI `setup-node` 从滚动 `22`/`24` 改为精确 `'22.20.0'`/`'24.0.0'`（带引号）。
- runtime contract 测试解析完整 major.minor.patch 并锁定精确下限。
- 新增 `tests/node-ffi-type-probe.ts`（`@ts-expect-error` 负向 fixture，由主 typecheck 覆盖）。

### 文档勘误

- CHANGELOG v1.1.5 和 ROADMAP M24 节注明 M24 未实际验证 missing `[Unreleased]`、generator 未实现 fail-closed 遍历和事务式发布、运行时下限只比较主版本。这些由 v1.1.6/M25 修复。

## 已知限制

- READ_EIN 权威字节数选择：需要目标器件数据手册或适用规范修订，blocked。
- DIRECT `device-datasheet` profiles：需要真实器件数据手册，blocked。
- 独立 FormulaEditor：optional，不是缺陷。
- PMBus 新版规范升级：独立工作，当前不得自动开展。
