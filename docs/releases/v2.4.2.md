# PMBus Calculator v2.4.2

PATCH release — 位字段网格密度回调（v2.4.1 修复的视觉余量补齐）。

> 2026-08-27 · PATCH（向后兼容）· PMBus Rev 1.3 / SMBus 3.0

v2.4.1 修好了位格越出卡片边框的溢出，但保留了 v2.4.0 放大的位格尺寸：收缩轨道上
位格行占满 nibble 卡片、贴合边框，视觉过于紧凑。本版本恢复 v2.3.0 的位格密度，
让 nibble 卡片内重新出现居中留白。

## Fixed

- **位字段网格过于紧凑**：按钮 36px→28px（flex-basis 1.75rem）、行间隙 4px→2px、
  cell 28px→24px。1370px 视口（4 列轨道收缩至 149.5px）下 nibble 卡片内视觉间隙
  从约 9px 恢复到约 16px，与 v2.3.0 观感一致。
- 收缩链与 minmax 轨道保持不变：全视口溢出矩阵复测（2048→360，10 档 × 5 模式 ×
  3 网格形态）仍为 0 溢出，v2.4.0 的卡片内溢出回归未复现。

## 基线审查（REPOSITORY_HYGIENE 3.10）

- 更新前失败场景 26 个（全部含可见位网格的场景）记为预期影响面；
- 更新 26 张基线，与影响面完全吻合；2 个无位网格场景不受影响未更新；
- 新旧成对对比 desktop-dark-l11 / mobile-390-vout-mode / mobile-390-l16-embedded
  三张关键基线，变化均为"位格缩小 + nibble 内留白增加"，无意图外差异。

## 规范结论（不变量）

- 计算与舍入语义、raw word、字节序与复制格式、命令元数据行为、持久化偏好全部不变；
  本版本仅 `tokens.css` 位格尺寸 token + 视觉基线 + 版本表面。
