# PMBus Calculator v1.1.5

PATCH 维护发行。修复 M23 审核发现的两项发布级门禁缺陷，不包含新产品功能。

## Fixed

- **Node 运行时下限类型合同**：`@types/node` 从 26（Current）改为 22（最低支持运行时），消除类型门禁接受 Node 22/24 运行时不存在 API 的 false-pass。新增 `tests/runtime-type-contract.test.ts` 结构性锁定引擎下限、CI 主/次验证与 `@types/node` 主版本一致性。
- **发布合同真实文件检查**：`scripts/check-release-contract.mjs` 重构为读取真实文件表面，不再自生成 `artifactNames` 循环校验。新增精确 Gregorian 日期验证、release notes 第一非空行精确标题匹配、README Live Demo 行版本校验、ROADMAP 唯一 stable 声明检查、lockfile 双版本必需验证。
- **发布合同集成级负向测试**：新增 13 个 fixture 集成测试，每个错误使真实 read+validate 链非零。
- **scripts checkJs 类型覆盖**：新增 `tsconfig.scripts.json`，根 tsconfig 扩展为四项目。七个 `scripts/**/*.mjs` 文件补全 JSDoc 类型注解，不降低 strict。
- **可复现发行资产生成**：新增 `scripts/prepare-release-assets.mjs`，从 `dist/` 确定性生成 zip 与 SHA256SUMS，相同 dist 两次生成逐字节一致。自动调用 `verify_release_zip.py` 与 `shasum -a 256 -c` 反向验证。

## Known Limitations

- `READ_EIN` 字节数仍依赖器件数据手册，保持 disabled。
- `DIRECT` device-datasheet profiles 仍 blocked，需要真实器件数据手册。
- 8 个 deployment E2E 测试在 main 套件中 skip（by-design，需 `DEPLOYMENT_URL` 环境变量）。
- 以上均为已知限制，非本次 PATCH 范围。
