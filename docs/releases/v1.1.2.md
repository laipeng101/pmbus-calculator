# PMBus Calculator v1.1.2

PATCH 修复发行：修正 v1.1.1 已确认的视觉一致性、文字对比度、公式语义和移动端密度问题。

发布渠道：GitHub Release（不发布 npm 包）。

## Fixed

- **文字对比度**：拆分 accent 前景/实心控件/实心上文字 token；暗色选中 tab、pressed 偏好、位按钮 on-bit、复制反馈均满足普通文字 ≥4.5:1。
- **公式语义**：DIRECT 参数面板使用 KaTeX 通用关系式；HALF 动态公式按 sign/exponent/fraction 展示 zero/subnormal/normal/±Infinity/NaN 分解；删除 L11 默认“未初始化”提示。
- **布局一致性**：Header / ModeSwitcher / CommandPicker / Workspace 左右 gutter 对齐；移动端统一 16px gutter。
- **复制工具栏**：6 列平衡网格；LE 字节 / BE 字节中文标签；复制字节序 segmented control；按钮在 340px 结果栏中单行不换行。
- **移动端位图密度**：360/390px 采用 2×2 nibble 布局；bit index 字号 10px；无 body 横向滚动。
- **视觉验收流程**：visual snapshot 回归保护与设计质量批准脱钩；新增 `npm run verify:ui`；snapshot 改用稳定场景名。v1.1.1 的 GitHub Markdown 渲染在当时已通过真实 GitHub 页面验证；原始过程截图仍可从 v1.1.1 tag 及历史 commit 追溯，当前 active tree 不继续保留这些一次性截图。

## Install / Run

```bash
npm ci
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 生产构建到 dist/
npm run preview  # 预览 dist/
```

## Build Artifact

`pmbus-calculator-v1.1.2-web.zip` 包含 `dist/` 的可部署静态内容。校验：

```bash
sha256sum -c SHA256SUMS.txt
```

## Known Limitations

- 自动化浏览器验证仍以桌面和移动 Chromium 为主。
- visual snapshot 为 darwin 基线，CI 默认不运行 `test:e2e:visual`。
- 当前规范基线为 PMBus Rev 1.3，不声明 PMBus 1.5 兼容。
