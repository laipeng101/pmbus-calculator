# PMBus Calculator v2.5.6

PATCH release — 修复物理值输入「无操作 focus/blur 重编码 raw 并伪造量化请求来源」
的 P1 缺陷；纠正 VOUT_MODE VID Code Type 的 Table 3 出处文案（明列保留 vs 未列出
保留）；移除矛盾的双重结构合法性事实源。

> 2026-08-28 · PATCH（向后兼容 bugfix）· PMBus Rev 1.3 / SMBus 3.0

## 诚实声明：显式编码行为与全部计算语义保持不变

v2.5.6 不改变任何编码/解码数学、舍入、饱和、字节序或复制合同。用户**真实编辑**
物理值后的提交行为（即时提交、blur 规范化、HALF 显式重输 `NaN` canonical 化为
`0x7E00`）与之前完全一致；修复只移除「未发生任何编辑时 blur 也会提交」这条错误
路径。明列保留 VID code 的分类结果（reserved、不可作为通用电压 profile）不变，
纠正的是出处说明文案。

## Fixed

- **无操作 focus/blur 重编码 raw 并伪造 provenance（P1）**：此前只 focus 后 blur
  （未编辑任何字符）就会派发 `value/set`：
  - HALF raw `0x7C01`（非规范 NaN payload）被静默改写为 canonical `0x7E00`——
    与同页 §7.6.2 特殊值卡「设备必须精确返回主机写入的 IEEE 编码」直接矛盾；
    binary16 的 2,046 个非规范 NaN 原码都可能被显示层往返合并，signaling/quiet
    信息丢失；
  - LINEAR11 raw `0801`（N=1,Y=1）被规范化为 `0002`（N=0,Y=2）：数值仍是 2，
    但 raw word 改变并新增伪造的 `0%` 量化误差；
  - 四个数值模式即使 raw 恰好不变也会伪造 `valueRequest`/`l11.valueInput`，
    使本应隐藏的「格式编码量化误差」显示为 `0%/特殊值`——违反
    DOMAIN_MODEL §6.1「未输入请求不是误差为零」的请求来源合同。
    现在 blur 事务化：当前 focus 会话内没有任何 `onChange` 编辑事务时，blur（含
    Enter 触发）是严格 no-op。dirty 判定依据真实编辑事务，不用解析数值比较
    （`NaN !== NaN`、`-0`、`1.0` vs `1` 文本差异都不可靠）。
- **VID Table 3 出处文案（P2）**：Table 3 明列 `01h..04h`（未来 Intel 处理器）、
  `10h..11h`（未来 AMD）、`1Ch..1Dh`（留作未来使用）、`1Eh/1Fh`（制造商自定义）；
  其余 code 才是未列出。此前 `0x21`（code `01h`）等明列保留 code 被写成
  「Part II §8.4.2 Table 3 未列出」。现在 `classifyVidCode` 机器区分五类出处
  （not-used / listed-reserved + family/reason / unlisted-reserved /
  profile-required），`resolveVoutModeRequirement` 拆分
  `vid-reserved-listed` / `vid-reserved-unlisted`，状态文本、InfoPanel、说明、
  计算步骤与结构化 VID code 下拉全部消费单一来源；明列 code 文案绝不含「未列出」。
- **移除矛盾的双重合法性事实源（P2）**：未使用的 `VoutModeAnalysis.isLegal`
  （`status === 'valid'`）与权威 `structureLegal` 对 `0x3E/0x3F` 矛盾
  （`isLegal=false` vs `structureLegal=true`）。字段与旧测试删除，结构合法性只由
  `resolveVoutModeRequirement().structureLegal` 输出。
- **VID code 下拉宽度**：更长的出处文案使无宽度约束的 `<select>` 固有宽度超出
  容器（360px 溢出）；补 `w-full min-w-0`。

## 验证

- 单元：45 files / 930 tests 全绿（新增 `classifyVidCode` 0..31 出处穷举与 label
  合同、绝对 VID bytes `0x20..0x3F` 逐 code requirement id 映射、0..256 字节
  结构合法/可计算/外部数据三维穷举保持）。
- E2E：新增 `tests/e2e/value-blur-lossless.spec.ts`（desktop/mobile 双项目）
  锁定 HALF `7C01`/`FC01`、L11 `0801`、L16 `0005`、DIRECT Y 编辑后的无操作 blur
  不变量与显式编辑对照路径；`vout-mode-half-matrix.spec.ts` 扩展
  `0x21`/`0x24`/`0x25` listed/unlisted 逐表面出处断言。
- 完整本地验证（`npm run verify` + `npm run test:e2e:visual`）在合并前运行；
  visual 基线预期零 diff（本版本只改 VID 保留态与 blur 行为，既有截图场景均为
  LINEAR 字节/有限值）。
- 规范依据对照官方 PMBus Rev 1.3 Part II 原文核对（§7.6/§7.6.2/§8.3 Table 2/
  §8.4.2 Table 3/§8.5.2/§8.5.3）。
