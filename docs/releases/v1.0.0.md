# PMBus Calculator v1.0.0

首次稳定发行。发布渠道：GitHub Release（不发布 npm 包）。

## Features

- 四模式双向转换：LINEAR11 / LINEAR16 (VOUT) / DIRECT / IEEE 754 Half-Precision。
- PMBus 命令字典：13 条 PMBus 1.3 标准命令；`project-demo` 预设仅在显式点击后应用。
- 复制工具：Hex、物理值、C 代码宏。
- 主题与偏好持久化：亮/暗主题、字节序、复制选项本地持久化。
- 严格输入校验与 READ_EIN 冲突呈现。
- 生产构建内置 CSP meta，无外部请求、无追踪。

## Install / Run

```bash
npm ci
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 生产构建到 dist/
npm run preview  # 预览 dist/
```

## Build Artifact

`pmbus-calculator-v1.0.0-web.zip` 包含 `dist/` 的可部署静态内容。下载后解压，通过任意 HTTP 静态服务器托管即可：

```bash
unzip pmbus-calculator-v1.0.0-web.zip -d pmbus-calculator-v1.0.0-web
cd pmbus-calculator-v1.0.0-web
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/
```

校验：

```bash
sha256sum -c SHA256SUMS.txt
```

## Known Limitations

- 当前规范基线为 PMBus Rev 1.3，不声明 PMBus 1.5 兼容。
- READ_EIN 不提供单一权威 packet length。
- device-defined 命令需要目标器件数据手册。
- DIRECT 不内置虚构 device-datasheet profiles。
- 自动化浏览器验证范围为桌面和移动 Chromium。
- 本次是源码及静态构建发行，不代表已有在线托管服务。
