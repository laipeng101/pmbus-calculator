# PMBus Calculator v1.1.7

PATCH release — 发布管线互斥锁、事务恢复、测试确定性与证据真实性。

## 概述

v1.1.7 对 v1.1.6 的发布管线进行加固，修复了六个在预变更探针中证实的实现缺陷。发行资产本身正确性不变，修复的是资产生成器在失败路径、并发安全、测试可重复性、Python 安全检查与合同验证方面的真实缺陷。

## 修复

### 原子并发锁与所有权（WP-A）

`acquireLock` 从非原子 `existsSync → writeFileSync`（TOCTOU 竞态）重构为 `fs.openSync(path, 'wx', 0o600)`（O_CREAT|O_EXCL 原子创建）。锁内容改为结构化 JSON 元数据（schema version、PID、timestamp、random nonce、repo realpath）。cleanup 仅删除 nonce/PID/repo 三方匹配的本进程锁。无效 JSON、EPERM、PID 状态不明、stale lock 均不得自动删除。新增 `--recover-lock` 显式恢复命令。`process.exit()` 不再出现在 try/catch 中，CLI 返回 exit code。

### 事务状态机与恢复（WP-B）

`generateAssets` 重构为显式事务状态机，每个阶段可注入依赖进行 failpoint 测试。`--force` 使用唯一 nonce 备份目录。新增 `--recover` 命令（output 缺失 + 已验证 backup 可恢复，output 与 backup 同时存在拒绝）。每个 failpoint 断言旧资产不丢失、无含糊状态、owned lock/staging 零残留。

### 测试确定性与路径安全（WP-C）

移除固定路径 `/tmp/.m25-symlink-probe`，改用 `fs.mkdtempSync` 并在 `afterAll` 清理。新增 20+ 并发竞争测试（严格一个 winner）。`catch` 使用 `unknown` 并正确 narrowing。

### Python ZIP helper TOCTOU 修复（WP-D）

`_zip_helper.py` 改为先 `os.lstat` 原始路径（检测 symlink），再 `os.path.realpath`（containment 校验）。POSIX 上优先使用 `os.open(..., O_RDONLY | O_NOFOLLOW)` 防 check-vs-read 替换。`external_attr` 包含 `stat.S_IFREG | 0o644`。

### 行为式 artifact contract（WP-E）

`check-release-contract` 改为导入 `getReleasePlan(version)` 并验证实际返回值，不再仅检查 import 字符串。`readContract` 返回 `generatorBehavioralOk` 与 `generatorBehavioralErrors` 字段。

### 锁清理与文档（WP-F）

`clean-generated.mjs` 增加 `.release-staging.lock` 到清理目标。`RELEASING.md` 新增"中断恢复"章节。v1.1.6 勘误记录在 CHANGELOG 中。

## 已知限制

- READ_EIN 权威字节数选择：需要目标器件数据手册，blocked。
- DIRECT `device-datasheet` profiles：需要真实器件数据手册，blocked。
- 独立 FormulaEditor：optional，不是缺陷。
- PMBus 新版规范升级：独立工作，当前不得自动开展。
