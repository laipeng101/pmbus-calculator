# PMBus Calculator v2.4.0

MINOR release — M39 中文优先界面 + 可访问术语气泡 + 字体角色统一 + 共享位字段网格。

> 2026-08-26 · MINOR（向后兼容）· PMBus Rev 1.3 / SMBus 3.0

本版本是一次产品语言与视觉系统修复：界面以中文为主语言，同一语义不再中英双写；
保留的 canonical 英文 token 改为可点按的术语气泡提供准确中文解释；VOUT_MODE 配置
摘要不再被当作数学公式排版；8/16 位编辑器共享同一位字段网格、四位分组与图例。
PMBus 数学结果、位域解析、raw lossless、字节序与复制合同均未改变。

## 新增交互

- **可点击术语气泡**：canonical token（VOUT_MODE、LINEAR/VID/DIRECT/IEEE Half 等）
  带虚下划线触发器；单一中文解释数据源 `src/app/terminology.ts`。气泡支持鼠标、键盘与
  触屏：点击开合、Escape 关闭并恢复焦点、点外关闭而气泡内不误关，同时只保留一个；
  `@floating-ui/react-dom` offset/flip/shift/size/autoUpdate 保证靠近视口四边不裁切，
  portal 渲染不推动布局。触发器为真实 `button`，携带 `aria-expanded/aria-controls/
aria-describedby`，不嵌套在其它交互控件内。
- **共享位字段网格**：`BitFieldGrid` 统一 16 位（4 nibble）与 8 位（2 nibble）编辑器；
  L16 内嵌 VOUT_MODE 使用 compact 密度但仍是两个有边界的四位分组，bits[6:5] 真正
  disabled 并在 ARIA 中说明“格式位固定为 LINEAR”；图例中文（指数 N [15:11]、尾数 Y [10:0]、
  符号位 [15]、数值 V/Y [15:0]、绝对/相对 [7]、格式 [6:5]、参数 [4:0]、0（未置位））。

## Changed

- **中文优先**：双语 explanation model 重构为中文主文案；规范化、说明、应用默认值、
  已关联/默认回退、绝对值/相对值等不再双语常驻；VID code 标签改为 未使用/保留/
  制造商自定义；位按钮 ARIA 形如“第 7 位，绝对值/相对值，当前为 0”。
- **字体角色统一**：UI = 系统无衬线；数据 = mono（Hex/binary/byte）；数学 = KaTeX 只用于
  真实公式。VOUT_MODE 结果摘要为配置视图（mono byte + UI token/状态），并区分
  合法/非法组合/参数非法/未使用/保留/需器件资料状态。
- 页面 `<title>` 补全 VOUT_MODE。

## 规范结论（不变量）

- VOUT_MODE 解析仍为 `(byte >> 5) & 0x03`；bit7 不混入 format；相对 + VID 非法；
  DIRECT/Half 参数必须为 00000b；SLINEAR16 为二补码偏移量（bit7 不参与）；官方示例
  `0x96` + raw `0x0466` → `R = 1.099609375`、加 `V_NOM = 3.3` → `3.6287109375 V`
  的 golden 全部保持。
