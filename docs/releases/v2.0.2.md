# PMBus Calculator v2.0.2

PATCH release — M35 工程质量加固，无用户可见行为变更。

## 概述

v2.0.2 不改变 L11 / L16 / DIRECT / HALF 的计算语义、持久化偏好或命令元数据行为。
本次只做三类内部工程优化：构建拆包消除 Vite 警告、提高并锁定单元测试覆盖率门槛、
清理全部 React inline style 并增加防回归门禁。

## 变更

### 构建拆包

- `vite.config.ts` 增加 `build.rollupOptions.output.manualChunks`：
  - `katex` 独立 chunk；
  - `react` / `react-dom` / `scheduler` / `@floating-ui` 合并为 `react-vendor`；
  - 应用主 chunk 从约 516 kB 降至约 64 kB（gzip 约 19 kB），不再触发 Vite 500 kB 警告。

### 覆盖率门槛与补测

- `scripts/vitest-shared-config.mjs` 门槛从 `80 / 80 / 70 / 80` 上调至
  `90 / 90 / 85 / 90`（lines / functions / branches / statements）。
- 新增/补充用例：
  - `PMBusMath.pow2` 的 `Math.pow` 回退分支；
  - `encodeLinear16` 的 clamp 行为；
  - HALF 次正规数进位到最小正规数；
  - `describeTransactionType` 全部事务标签。
- 当前实际覆盖率约：statements 95.86% / branches 93.82% / functions 97.84% / lines 98.13%。

### Inline style 清理与门禁

- 移除 `src/` 下全部 React inline `style` prop（约 80 处），迁移至
  `src/styles/tokens.css` 的语义 class 与 data 属性。
- 新增 `scripts/check-inline-style.mjs` 与 `tests/check-inline-style.test.ts`；
  新增 `npm run check:inline-style`，并接入 `npm run verify`、`npm run check` 与 CI quality job。
- `HexInput` / `IntegerInput` / `DecimalInput` 不再暴露 `style` prop。

## 已知限制

- READ_EIN 权威字节数选择：需要目标器件数据手册，blocked。
- DIRECT device-datasheet profiles：需要真实器件数据手册，blocked。
- PMBus 新版规范升级：独立工作，当前不得自动开展。
- 本版本不覆盖：总线传输、命令执行、设备 Profile、PMBus 1.5 安全扩展与 Part IV。
