# PMBus Calculator v1.1.0

向后兼容的新展示能力发行：统一 LaTeX 数学公式展示与交互反馈系统。

发布渠道：GitHub Release（不发布 npm 包）。

## Features

- Markdown 数学公式：`README.md`、`README_zh-CN.md`、`docs/DOMAIN_MODEL.md` 等活动文档中的数学表达式使用 GitHub 支持的 `$...$` / `$$...$$` LaTeX 语法。
- Web 公式 KaTeX 排版：新增 `src/components/math/MathFormula.tsx` 与 `src/app/formula-presentation.ts`，四种模式均从同一公式层取得纯文本与 LaTeX；KaTeX 使用本地 npm 依赖、HTML + MathML 输出，并带纯文本 fallback。
- 交互反馈系统：统一 cursor / hover / active / focus-visible / disabled 状态矩阵；支持 `prefers-reduced-motion`；popover 与复制反馈使用轻量 CSS 动效。
- 兼容性：PMBus 计算、舍入、编码、字节序、复制输出和 C 宏注释语义保持不变。
- Release/Pages smoke：生产构建与真实 Pages 部署均验证 KaTeX CSS、字体与 MathML 输出，资源保持 Pages 同源。

## Install / Run

```bash
npm ci
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 生产构建到 dist/
npm run preview  # 预览 dist/
```

## Build Artifact

`pmbus-calculator-v1.1.0-web.zip` 包含 `dist/` 的可部署静态内容。下载后解压，通过任意 HTTP 静态服务器托管即可：

```bash
unzip pmbus-calculator-v1.1.0-web.zip -d pmbus-calculator-v1.1.0-web
cd pmbus-calculator-v1.1.0-web
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/
```

校验：

```bash
sha256sum -c SHA256SUMS.txt
```

## Known Limitations

- 当前规范基线为 PMBus Rev 1.3，不声明 PMBus 1.5 兼容。
- READ_EIN 不提供单一权威 packet length。
- device-defined 命令需要目标器件数据手册。
- DIRECT 不内置虚构 device-datasheet profiles。
- 自动化浏览器验证范围为桌面和移动 Chromium。
- 公式不接受用户输入任意 TeX；仅内部受控模板通过 KaTeX 渲染。
