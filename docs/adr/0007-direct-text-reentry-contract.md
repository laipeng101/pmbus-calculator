# ADR 0007 DIRECT 显示值的重新输入与复制

用户重新输入的是页面上看到的文本。例如 `m = 1, b = 1, R = 12, Y = -1` 的精确值为 `-1.000000000001`，显示为 `-1`。即使解码后的浮点数可以重新编码为 `Y = -1`，输入屏幕上的 `-1` 仍会得到 `Y = 0`。

因此由 `analyzeDirectTextReentry` 按实际输入路径判断显示文本重新编码后是否改变 `Y`。浮点表示和显示位数都可能造成差异，`lossKind` 区分两种原因。结果提示、复制说明和计算步骤都使用同一分析，具体行为见 [DIRECT 领域规则](../DOMAIN_MODEL.md#23-direct)。

回归测试对 `(m, b, R) = (1, 1, 12)` 遍历全部 65,536 个 `Y`，通过实际复制逻辑取出文本，再经 reducer 重新输入并核对原始字。浏览器测试还从另一数据字粘贴精确值，确认原数据字可以恢复。
