# ADR 0003 原始数据字与字节表示分离

以前 LINEAR16 的 Hex 输入随字节序偏好改变含义，同一个数据字可能在 Hex、位网格和复制结果中分别显示为 `8FC3` 和 `C38F`。输入同一文本也可能因用户之前选择的偏好而得到不同结果。

主 Hex 输入、位网格、换算和 C 宏统一使用 `state.raw`。线上字节和高字节在前的表示只在显示与复制时生成。旧版保存的 `byteOrder` 和 `copy.endian` 继续忽略，避免影响升级后的输入解释。[字节序规则](../DOMAIN_MODEL.md#4-原始数据字与字节序) · [读取偏好](../../src/app/persistence.ts)
